# 29 期望值与利益冲突（Expectation and Conflict of Interest）

> 5 名法官，每人有 10 位近亲，全国 6% 的人住在被封锁的地方。**"按统计，你们当中该有 3 名亲属在那里"。如果一个都没有呢？** —— 期望值不只是用来求"平均数"的，它还能反过来检验一个群体是否**有代表性**。

## 1. 它是什么

**期望值**（expectation）是随机变量取值的**加权平均**：

$$E[X] = \sum_i x_i \cdot p_i$$

- 掷一颗均匀骰子：$E = 1\times\frac16 + 2\times\frac16 + \cdots + 6\times\frac16 = 3.5$
- 跑 50 次模拟得到"平均车速"，那就是期望的**估计**

**关键性质：期望是线性的**。对任何随机变量 $X, Y$ 和常数 $a, b$：

$$E[aX + bY] = aE[X] + bE[Y]$$

**不需要独立性！** 这条性质极其好用，可以让你**用局部的平均推断整体的平均**，而不用知道任何分布。

## 2. 小说里它在干什么

第 26 章，一场关于调税的诉讼。凯隆法官提出回避自己（因为他有 3 个孩子被封锁在大梅港），另一位法官凯尔隆提出一个完全不同的论点。

> 「维里迪亚有6%的人口住在北岸。每个人大约有10位近亲——父母、兄弟姐妹、子女、配偶、其他近亲、共同家长。那么**你们5个人加起来就是50位**，所以**按统计，你们当中总共该有3名亲属在北岸**。**如果你们一个都没有，那你们就没有感受到许多其他维里迪亚人正在感受的东西。也就是说，你们的利益是错位的。你们错位到了麻木自满那一边——可这难道不也是一种不当影响吗？**」
> ——第26章，chapter-26.md:371

**算术本身很简单**：

$$5 \times 10 = 50 \text{ 位近亲} \qquad 50 \times 0.06 = 3 \text{ 人}$$

**但这个论证的结构极不寻常，值得仔细拆：**

1. **正向论证**（先例支持回避）："我的利益受影响，我应该回避" —— 常规思路
2. **反向论证**（本案采用）："**如果你没有受影响的亲属，你就是异常样本，你的视角不代表任何人**" —— **用期望值论证代表性**

**这实际上是在用期望值做"抽样的合理性检验"**：如果一个群体是从总体里**随机抽**出来的，那么群体的构成应当与总体的构成**统计上一致**。**5 个人 × 10 近亲 = 50 个抽样点，只期望 3 个在北岸。零个在北岸的概率是 $(0.94)^{50} \approx 4.5\%$——这是一个统计上相当不寻常的样本。**

**这个手法在现实中非常常见**：陪审团、董事会、专家组的"利益冲突"审查，本质上都是这类统计代表性检验。

## 3. 直觉：平均值不是"平均的那个值"

**期望值经常让人误解。** 掷骰子的期望是 3.5，但**你永远不会掷出 3.5**。

期望值回答的是：**"大量重复试验后，长期平均值会趋向多少？"**

**要区分三件事**：

| 概念 | 问的问题 |
| --- | --- |
| **期望值** | 长期平均是多少？ |
| **最可能值（众数）** | 最常出现哪个？ |
| **中位数** | 一半比它大、一半比它小？ |

**书里这三种含义恰好是分开用的**：
- "按统计该有 3 名" = **期望值**
- "如果你们一个都没有" = **在谈一个低概率事件**（用了 0 个而不是 3 个）
- 真正要问的其实是"该不该回避" = **一个制度问题，不是数学问题**

## 4. 原理

### 4.1 线性性：期望的真正威力

**这是本节最重要的一条，也是书里那句"5 个人加起来 50 位"能成立的根据。**

设 $X_i$ = 第 $i$ 个近亲是否住在北岸（1 或 0），$X = \sum_{i=1}^{50} X_i$。

$$E[X] = E[X_1 + X_2 + \cdots + X_{50}] = \sum_{i=1}^{50} E[X_i] = 50 \times 0.06 = 3$$

**注意：这里完全不需要 $X_1, \ldots, X_{50}$ 互相独立！** 线性性是**无条件成立**的。

**这是一个非常强大且反直觉的事实**：

> 即使 50 个近亲高度相关（比如都在同一个大家族里），**期望依然是 3**。
>
> 你不能**保证**真的有 3 个（现实里可能是 0 个或 6 个），但**平均值在期望上必然是 3**。

**这就是为什么能用期望做论证**：它是一个**平均意义上必然成立**的陈述，而不是一个**确定成立**的陈述。

### 4.2 服从二项分布的版本

如果我们**额外假设**（每人独立决定去不去北岸），那么 $X \sim B(50, 0.06)$，是**二项分布**：

$$P(X = k) = \binom{50}{k} (0.06)^k (0.94)^{50-k}$$

**零个的概率**：

$$P(X=0) = (0.94)^{50} \approx e^{50 \ln 0.94} = e^{-3.087} \approx 0.0456 \approx 4.6\%$$

**恰好 3 个的概率**（书里"按统计该有 3 名"）：

$$\binom{50}{3}(0.06)^3(0.94)^{47} \approx 19600 \times 0.000216 \times 0.0506 \approx 0.214 \approx 21.4\%$$

**解读**：最可能的情况（21.4%）确实是 3 个，而**一个都没有**虽然不是最可能，但也有 4.6%——**不算特别反常。**

> **必须诚实指出**：这 4.6% **并不构成"你们撒谎了"的证据**。凯尔隆的论证在"你们真的一个都没有"这个前提下是**有力**的；但"一个都没有"本身有约 4.6% 的概率自然发生。**所以严格地说，这个论证是"值得怀疑"而不是"证明有偏"。** 认清这个区别很重要——**很多看起来很有力的统计论证，其实只是把一个 5% 的偶然事件当成"不可能"。**

### 4.3 期望 vs 分布：一个必须分清的层次

在真实场景里，"5 个法官"不是随机抽的，50 个近亲也不是独立决定的。所以：

- **期望 = 3 是必然成立的**（由线性性，无条件成立）
- **"最可能是 3 个"需要独立性假设**（书里没有明说，但第 27 章"按二项式公式"的说法在 [27](27-binomial-distribution.md) 里就是明确用了独立性）

**作者在书里其实很小心**：他说的是"**按统计**，你们当中总共**该有** 3 名亲属"——"该有"暗示的是**期望**，而不是"必然是 3 个"。**这个措辞是准确的。**

## 5. 关键参数与现实取值

**用期望做代表性检验的现实例子**：

| 场景 | 检验内容 |
| --- | --- |
| **陪审团** | 是否有种族、性别、年龄的分布异常 |
| **董事会** | 是否有利益冲突的过度集中 |
| **专家证言** | 该专家的经验分布是否与待评估总体匹配 |
| **立法机构** | 席位分配是否按人口（见第 5 章的几何平均） |
| **配比委员会** | 新制度下团体的组成是否符合设计意图 |

**相关的概念：**

- **标准差** $\sigma$：期望的离散程度。书里只用了期望，**但严格的代表性检验必须同时看方差**（一个期望为 3 但方差极大的群体，和一个期望为 3 且集中的群体，代表性完全不同）。
- **卡方检验**（chi-square test）：检验"观测计数是否符合期望计数"的**标准统计方法**。书里那个论证本质上是卡方检验的**口头版本**。
- **超几何分布**：当"50 位近亲"来自一个**有限总体**且**不放回抽样**时用它（这更接近现实！）。**注意：如果近亲之间高度重叠（比如夫妻互相是近亲），超几何模型也不对。**

## 6. 容易误解的地方

**误解一：「期望是 3，所以应该正好有 3 个。」**
**不是。** 期望是**长期平均**，不是"典型的一次结果"。5 个人是 5 个样本，不是 5 万个样本。**样本量小的时候，期望的实际参考价值有限。** 书里那个论证的说服力，有一部分其实来自修辞（"按统计该有"听起来很权威），而不是来自统计强度。**认清这一点是读这本书的必要能力。**

**误解二：「期望是 3，证明这 5 个人有偏。」**
**不能证明。** 如上算出，一个都没有的概率约 4.6%——不低。**这个论证最多说"值得调查"，不能说"有罪"。** 而且还存在另一个致命问题（见误解三）。

**误解三：「50 个近亲是 50 个独立样本。」**
**不是。** 家庭成员**高度相关**：
- 兄弟姐妹往往住在同一个城市
- 配偶往往来自同一个地方
- 共同家长意味着**两个家庭重叠**

**如果 5 位法官的近亲有大量重叠，实际的"有效样本量"远小于 50**，期望仍然是 3（线性性保证），但**方差会小得多**——也就是说，"一个都没有"会**更罕见**。**这是对凯尔隆有利的方向**，但也说明这个论证的模型不严谨。

**误解四：「有利益冲突就应该回避。」**
**这是制度问题，不是数学问题。** 书里紧接着的对话就展示了这个张力：

> 「那些法律不是这么运作的，这方面有先例。」
> 「那**你**在北岸有家人吗？如果有，那**你**才是受不当影响的那一个。」
> 「这回是你不懂法了。原告本来就允许与案件结果有利害关系——事实上，是必须有利害关系。这个法律术语叫**诉讼资格**。」
> ——第26章，chapter-26.md:371

**这正好是"代表性 vs 程序正义"的对立**：一方用统计代表性说"你该回避"，另一方用程序正义说"**利益相关恰恰是诉讼资格（standing）的一部分**——如果没人受影响，反而说明原告是空想的"。

**这两个立场都有道理，且都不是数学能裁决的。** 这正是本书反复出现的主题：**数学能告诉你"有多少"，但不能告诉你"应该怎样"。**

**误解五：「用期望做论证很严谨。」**
**期望是严谨的，但"把期望当典型值"是不严谨的。** 这是最常见的统计谬误之一。**期望 + 方差 + 分布形状，三者缺一不可。**

## 7. 自己动手试试

**A. 验证线性性不需要独立性。** 想一个反例：$X = Y$ 总是 $Y$（完全相关）。
$$E[2X] = E[X + X] = E[X] + E[X] = 2E[X] \quad ✓$$

**即使 $X$ 和 $Y$ 完全相同（相关性 1.0），期望的加法仍然成立。** 这就是线性性的威力。**对比**：$E[XY] = E[X]E[Y]$ **只在独立时成立**。**这两条的区别是初学者最容易混淆的地方。**

**B. 亲手算书里那个论证的全部分布。** 50 个近亲、每人 0.06 的概率（假设独立）：

| $k$ | $P(X=k)$ |
| --- | --- |
| 0 | 4.6% |
| 1 | 14.6% |
| **2** | **22.2%** |
| **3** | **23.1%** |
| 4 | 22.3% |
| 5 | 16.8% |
| 6 | 10.0% |

**验证 $P(2) = \binom{50}{2}(0.06)^2(0.94)^{48} \approx 1225 \times 0.0036 \times 0.0539 \approx 0.238$**（用 $\binom{50}{2} = 1225$）

**结论：2–4 个都是高概率区间，"恰好 3 个"并不是特别突出。** 这个计算会让凯尔隆的论证显得**没有想象中那么精确**——**但它的"0 个很反常（4.6%）"这一点仍然成立。** 请自己把这一行算一遍。

**C. 思考一个真实问题。** 某公司董事会 9 人。已知：①该国 50% 的人口在某年龄段；②董事会 9 人中有 2 人来自该年龄段。**董事会有问题吗？**
> 期望：$9 \times 0.5 = 4.5$ 人。观测到 2 人。
> 用二项分布：$P(X \le 2) \approx$ 算一下 $\binom{9}{2}(0.5)^2(0.5)^7 + 9 \times 0.5^9 + 0.5^9 = 36 \times 0.0039 + 9 \times 0.00195 + 0.00195 \approx 0.1406 + 0.0176 + 0.0020 = 0.16$。
> **约 16% 的概率**。**这不能说明有问题。**
> **教训：16% 的 p 值在科学上根本不算显著。** 期待值远离观测值，不等于观测值不可能。

## 8. 自测

**Q1.** 期望 $E[X] = 3$（50 位近亲中住在北岸的），为什么这**不能**推出"应该正好有 3 位"？

> **答案**。期望是**随机变量的加权平均**，描述的是**大量重复试验的长期平均**。这里样本量只有 50，即使把它当作抽样，也是一个很小的样本。**期望 3 意味着均值在期望上必然是 3，但单次实现可以是 0、1、2 或 6 个。**
> 而且实际观测有 4.6% 的概率就是 0 个——**不低**。所以"期望为 3"只能支持"值得注意"，不能支持"证明有偏"。

**Q2.** 为什么 50 个近亲即使高度相关，期望仍然是 3？

> **答案**。因为**期望的线性性是无条件成立的**：$E[aX + bY] = aE[X] + bE[Y]$ **不需要任何独立性假设**。
> 推论很重要：**独立性只影响方差，不影响均值。** 所以无论 50 位近亲之间的相关性多强（兄弟姐妹住同城、配偶重叠等），**"平均而言有 3 人在北岸"这个陈述都是稳的**；但"实际会是 3 个的概率"以及"一个都没有的概率"则高度依赖相关结构。
> **对比记忆**：$E[XY] = E[X]E[Y]$ 才需要独立。

**Q3.** 书里凯尔隆的论证，用统计学的语言精确地讲是什么？它的强度如何？

> **答案**。它是一个**代表性/构成比的统计检验**——用一个**期望计数**（expected count）来评判**观测计数**（observed count）在统计上是否寻常。
> 精确地说：它没有做完整的假设检验，而是**单边地指出"0 属于低概率事件"**。
> **强度评估**：$P(X=0) \approx (0.94)^{50} \approx 4.6\%$。**这是一个"不寻常但不极端"的事件。** p = 0.046 远不算显著（科学界通常要求 p < 0.05 只是"勉强显著"，而这还依赖独立性假设，而近亲之间明显不独立）。
> **所以诚实的结论**：这个论证**作为质疑是有力的**（它准确指出了一个值得解释的异常），**作为证明是不足的**。书里紧接着凯隆的反驳（"原告本来就允许与案件结果有利害关系……这个法律术语叫诉讼资格"）正是在这个意义上构成了对等回应。
