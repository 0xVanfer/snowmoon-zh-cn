# 《雪月》概念科普 · 总目录

> 这是一个副工程：从《雪月》正文里把**真实存在的** Web3 / 密码学 / 本科以上数学概念挖出来，
> 每一项单独写一篇面向「聪明的中学生」的科普／教程。
>
> 目标读者假设：你能轻松处理分数、百分比、简单概率，但没有接触过
> 密码学、博弈论、机器学习。**所以每篇都从直觉讲起，数学只推到你真的需要看懂的那一步。**

## 这套文档是什么

《雪月》是 Vitalik Buterin 写的科幻小说，但它的世界观不是随口编的：
里面跑的每套机制几乎都能在现实里找到对应物——二次方资助、密码学抽签、
零知识抵押、混网、语言模型隐写、混淆电路、基于哈希的签名、梯度下降对抗补丁……
作者把它们组装成了一个社会，这套文档就是把这个「零件库」拆开给你看。

每篇回答四个问题：

1. **它是什么**（一句话 + 一个生活化的类比）
2. **小说里怎么用的**（给出章号、原文短引，指出它承担了哪个功能）
3. **它到底怎么运转**（原理、必要时的数学推导、关键参数）
4. **容易误解的地方**（以及真实世界里它被攻破过几次）

`book/chapters/chapter-NN.md:行号`，方便核对。原文短引不超过 30 字，**不得改写**。

## 明确排除的内容

以下东西在书里大量出现，但**不是真实世界的技术／数学概念**，因此不写：

- **虚构设定**：民本棋及其规则（异或不变量除外，见 03）、神龛、光尺与泽国的百进制计时、
  翔球（计分博弈除外，见 34）、隔信箔、隐私袍、算力盒、齐普币（作为货币设定）。
  文档里提到它们时一律标注「这是小说设定」。
- **纯制度名词**：掌舵会、合议庭、评则、掌则人、公民大会、共同家庭等。
  它们只在需要解释机制时被引用（如 `web3/21` 讲二次方资助时会提到「评则」是它的产物）。
- **日常道具**：无人机本身、手表、手持终端、无人机挂载的武器硬件。

## 已知缺口

如实记录，避免误以为「已完备」：

- **书中说错处**：`crypto/07` 指出第 9 章那句「只有知道 p 乘 q 的人才能解密」**不准确**（知道 $n$ 不足以解密，需要 $\varphi(n)$），并把它当作「怎么判断哪句是作者借人物之口说反话」的示例。
- **书里未给出的实现细节**：作废符如何做到「由公开评语生成却不可关联」、抵押率与信誉分阈值、投票密钥登记的具体参数——相关文档均标注「书中未给出」，不臆造。
- **未能核实的文献**：审议性随机样本的实证研究、CONIKS 论文、海森堡扩展原始论文——只列作者与篇名，**不给 URL**。
- **第 22 章「抗噪能力很强」→「容错能力很强」**：原文 "noise-tolerant" 指对信号丢失（擦除）的鲁棒性，即容错能力；直译作「抗噪」易被误读为可纠正随机误码。已改译，并在 `translations/zh/chapter-22.zh.json` 的 `translator_notes` 记入说明（按仓库体例不随正文上线）。
- **第 19 章 "five-of-six erasure code"**：统一译作「6选5纠删码」（体例规定纯数字与汉字间不留空格），`pipeline/glossary.json`、译文 `new_terms` 备注与正文已同步。
- **未展开的深度**：格密码的 SIS/LWE 数学、zk 证明系统的多项式承诺与约束系统、Nim 的 Sprague–Grundy 一般理论、卷积/softmax 等模型训练术语——**书中并未出现**，故不写。
