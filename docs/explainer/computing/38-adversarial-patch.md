# 38 对抗补丁（Adversarial Patch）

> 攻击一个图像识别模型，最有效的办法不是偷偷改几个像素，而是**往它面前贴一张醒目的贴纸**。模型会盯着那张贴纸看，然后完全看不见你真正的目标。

## 1. 它是什么

**对抗样本**（adversarial example）指：一张被精心修改过的图像，人眼看几乎没变，但模型判断错了。

**对抗补丁**（adversarial patch）是它的一个变种，也是最实用的一个：

> 不做"隐蔽的修改"，而是做一块**明显的、有意设计的图案**，印出来贴在物体上，让模型把注意力全被它吸走，从而做出你指定的判断。

经典的演示（Brown, Goodfellow, et al. 2017）：一个 VGG16 模型以 97% 置信度正确识别出一根香蕉；旁边贴上对抗补丁后，模型以 99% 置信度报告"烤面包机"，**完全无视那根香蕉**。

## 2. 小说里它在干什么

第 29–30 章，泽国要给每一台雪地无人机**贴一张纸**。

> 「你可以拿模型在模拟器里的输出结果，对我们在战场上能改的所有变量求导——**我们贴在无人机侧面的图案**、无人机的动作方式。系统会自动找出那个能把'它们的模型漏掉我们的无人机'这一概率抬到最高的小改动。」
> ——第29章，chapter-29.md:273

最终成果长这样：

> 「他看到一长排望不到头的雪地无人机，每一台四面都糊着大张的纸，每张纸上都有许多彩色、弯弯曲曲的图案——**还有一个用硕大字体印出的词：狗**。」
> ——第30章，chapter-30.md:95

**「狗」这个硕大的词，正是最符合真实研究的细节。** 原始对抗补丁论文里，图案优化出来就是**高对比度、语义上莫名其妙的色块**，看起来像"致幻剂"。研究者后来发现，**把补丁做得更大、更显眼、更不像自然图像，反而更有效**——因为模型的注意力机制会被显著性（saliency）吸引。

而且书的描述完全对：**这些图案在人类看来是"一堆看不懂的鬼画符"**（chapter-29.md:275）。

**第 22 章还有一个更早期的、更小的版本**：

> 「最好还能被认成北极的无人机」（伪装成敌机甚至动物）
> ——第22章，chapter-22.md:207

## 3. 直觉：为什么"显眼"反而更好

这一点违反直觉，值得慢慢想。

传统对抗样本追求**不可察觉**：每个像素只改一点点，让人眼几乎看不出。但这样的扰动**脆弱**——光照一变、压缩一次、图像缩放一下，就失效了。

**对抗补丁反其道而行：我要的就是显眼。**

理由是：神经网络判断图像时，会计算每个区域的**"显著程度"**（有多少注意力分配给它）。一个色彩强烈、形状怪异的贴纸，其显著性**远超**背景里的真实物体。模型于是把主要注意力给了贴纸，**真实目标的特征根本没被充分提取**。

一句话：

> **你不需要骗过模型的眼睛，你只需要比真正的目标更吸引模型的注意。**

## 4. 原理

### 4.1 数学形式

对抗补丁是一个受限的优化问题。设原图 $x$，补丁区域用二值掩码 $p$ 表示（1 表示补丁覆盖的地方）：

$$x' = (1-p)\odot x + p\odot \delta$$

其中 $\delta$ 是我们优化的补丁像素。

目标是最大化目标类别的对数概率：

$$\hat{\delta} = \arg\max_{\delta}\; \mathbb{E}_{x\sim\mathcal{X},\,l\sim\mathcal{L},\,t\sim\mathcal{T}}\Big[\log M\big(\hat{y} \mid A(x, l, t, \delta)\big)\Big]$$

- $M(\cdot)$：模型输出的**分类概率分布**
- $A(\cdot)$：把补丁贴到图像上的操作
- $l$：补丁**位置**的分布
- $t$：**变换**的分布（旋转、缩放、光照、模糊、打印噪声）
- $\hat y$：我们希望模型误报成的类别

**为什么要对 $t$ 取期望（EOT）**——这是让补丁"能用"的关键，见 4.2。

### 4.2 EOT：为什么必须在优化时就考虑"会歪"

数字世界里，补丁是精确的像素。现实世界里：

- 贴纸会因拍摄角度而**透视变形**
- 印刷会损失精度，纸张反光
- 光照会变（室内/室外/逆光）
- 距离和摄像头焦距不同 → 补丁在画面里的大小不同
- 运动模糊

**如果只针对"完美的一帧"优化，真实世界里一歪就废。**

EOT 的做法是：**在优化过程中就随机采样各种变换，并要求补丁在所有变换下都有效。**

$$\max_{\delta} \; \mathbb{E}_{t\sim\mathcal{T}}\big[\log M(\hat y \mid t(A(x,\delta)))\big]$$

这等价于：**优化一个"对所有歪法都稳健"的补丁。** 时间尺度分离在这里同样重要：变换分布要覆盖真实世界的主要变化，采样次数要够多。

### 4.3 通用性与迁移性

补丁还有一个强大性质：**通用性**（universal）与**迁移性**（transferable）。

- **通用**：同一个补丁贴在**任何**图像上都能触发误判。
- **迁移**：在模型 A 上训练出的补丁，贴给模型 B 也有效。

**迁移性为什么重要**：攻击者通常**拿不到**目标模型的权重（见 [37 梯度下降](37-gradient-descent.md) 和 [39 黑盒查询攻击](39-black-box-query-attack.md)）。但如果补丁能迁移，就可以在自己的模型上优化，然后直接用。

**书里对此有清醒的认知**：

> 「换不同参数的模拟器去试——记住，最后的攻击会出现在真实世界里，而不是模拟器里，所以我们能做到的，只是**筛出在不同模拟器上都稳健的改动**。跑个100万轮之后，希望我们能得到一套在现实中相当管用的东西。」
> ——第29章，chapter-29.md:275

**这正是迁移性的实践版本：把"不同参数的模拟器"当作"不同模型"，能同时骗过它们的改动，才更可能迁移到目标模型。**

### 4.4 三种攻击的对比

| | 不可察觉扰动（FGSM/PGD/C&W） | 对抗补丁 |
| --- | --- | --- |
| 幅度 | 极小（$\ell_p$ 受限） | **无限制，明显可见** |
| 物理可用 | 差 | **好（打印即可）** |
| 通用性 | 一般针对单张图 | **通用** |
| 迁移性 | 较弱 | **较强** |
| 易被发现 | 难 | **容易（显眼）** |
| 主要用途 | 评测模型鲁棒性 | **真实攻击** |

**一个重要的现实提醒**：由于补丁很显眼，防御方可以用**专门的补丁检测器**——找出图像中那些统计特征异常、语义不连贯的区域。这是攻防的真实拉锯。

## 5. 关键参数与真实数字

**效果评估指标**：分类攻击看"目标类别的置信度"；分割/检测攻击看 **mIoU**（mean Intersection over Union，预测掩码与真值的重叠比例）的下降。

**鲁棒性衰减的真实规律**（很重要）：

- **距离**：补丁离目标越远，攻击成功率**下降很快**。这与"显著性能吸引注意力"一致。
- **旋转**：绕 z 轴旋转超过约 20°，效果显著下降。
- **遮挡**：部分遮挡仍然有效，但持续下降。

**书里的战果**（第 30 章，交叉引用 39/43）：

| 阶段 | 侦测时间优化幅度 |
| --- | --- |
| 初始 | 5% |
| 改进后 | 11% |
| 再优化 | **翻倍** |
| 再次优化 | **再翻倍** |

> 代价是：北极切断模拟 API 访问后，泽国这边的效果**跌回 1.5:1 的伤亡比**（原本拉到了 6:1 甚至一度 10:1）。
> ——第30章，chapter-30.md:9 附近的情节

**这个数字落差极其重要**：它量化了"知识不对称"的价值。**只要对手还能提供查询接口，对抗攻击就能持续进化；一旦切断，就立刻退回。**

## 6. 容易误解的地方

**误解一：「对抗样本说明 AI 很蠢，一眼就能骗。」**
**恰恰相反，它说明的是深度网络的一个根本脆弱性。** 人类识别物体靠的是**结构化的、组合的**理解（"香蕉是弯的、黄色、有柄"），而 CNN 很大程度上靠**局部纹理统计**。对抗补丁利用的正是后者：**它不需要"骗过"任何语义推理，只需要抢走注意力配额。**

**误解二：「补丁必须隐形才有用。」**
**这是针对传统对抗样本的误解。** 补丁之所以有效，恰恰因为它**可见**。有一条研究线专门做**"隐蔽对抗补丁"**——比如用扩散模型把补丁生成得自然（像草地上的涂鸦、衣服上的花纹），这属于另一个研究方向。

**误解三：「攻击有效 = 模型彻底坏了。」**
**不是。** 补丁攻击通常只对**特定任务**（如目标检测的"不发现"）有效，对分类任务的破坏有限。**局部失效 ≠ 整体崩溃。**

**误解四：「只要模型是人训的，就一定会被补丁骗。」**
不一定。防御手段相当多：
- **对抗训练**：训练时就加入对抗样本，让模型学会抵抗
- **输入预处理**：平滑、去噪、JPEG 压缩后再处理
- **专门检测器**：专门找"不自然"的区域
- **多视角一致性检查**：用多个摄像头不同角度判断
- **可证明鲁棒性**（certified robustness）：给出数学保证，如随机平滑（randomized smoothing）在 $\ell_2$ 范数下的保证

**但必须诚实说：目前没有任何一种防御能保证完全有效。** 攻防是持续的军备竞赛。

**误解五：「AI 这么脆弱，那用它做决策很危险。」**
**这个推论是合理的，但要区分层次。** 深层系统（卡车、电网、武器）依赖**系统级防护**（冗余、验证、权限隔离、人工复核），而不是指望单个模型绝对可靠。书里第 32 章的"分布式免疫系统"（chapter-32.md:189）正是这个思路：**不指望单点免疫，而指望网络整体免疫。**

## 7. 自己动手试试

**A. 理解"显著性"的机制。** 想象你把一张亮黄色的大贴纸放在一张暗色照片中间。人的注意力会立刻被吸引——这是人类视觉的**显著性**（saliency）。

神经网络的 **CNN** 里有一个模块叫 **注意力/显著图**（saliency map），它做的事和人类视觉非常像：指出"哪些像素对最终判断最重要"。

**对抗补丁的原理就是：让补丁的显著图面积远大于真实物体。** 这是可以自己验证的——把补丁去掉再放回去，对比显著图，你会看到模型"看"的地方完全变了。

**B. 亲手做一个最小版。** 用纸笔模拟：
1. 画一个简单图像（比如一个"+"和一个"×"）
2. 在"+"旁边画一个斑马纹的方块
3. **先问自己**：如果你是看图软件，你会先看哪个？
4. 现在假设软件的"决策逻辑"是"哪块区域细节最多"——那么斑马纹会赢，即使它毫无意义

**这个实验不能真正攻击模型，但能建立正确的直觉：显著性压倒了语义。**

**C. 估算攻击的鲁棒性衰减。** 已知：补丁离目标距离 $d$ 时，攻击成功率 $p(d) = p_0 \cdot e^{-\alpha d}$。若 $p_0 = 0.9$、$\alpha = 0.3$：
- $d=1$：$p = 0.9 e^{-0.3} \approx 0.67$
- $d=3$：$p = 0.9 e^{-0.9} \approx 0.37$
- $d=5$：$p = 0.9 e^{-1.5} \approx 0.20$

**距离每增加 2，成功率大致减半。** 这就是为什么真实攻击必须**贴近**目标，而且这是可量化的工程约束。

## 8. 自测

**Q1.** 为什么对抗补丁**做得显眼反而更有效**，而不是越隐蔽越好？

> **答案**。因为神经网络通过**显著性**分配注意力。补丁的目标不是"骗过眼睛"，而是"**比真实目标更吸引注意力**"。高对比度、怪异形状的图案，其显著性远超背景里的真实物体，模型于是把主要注意力给了补丁，真实目标的特征提取被严重不足。**隐蔽性对数字域对抗样本很重要，对物理补丁反而是负资产**——它太容易在物理变化中失效。

**Q2.** EOT（变换上的期望）在对抗补丁里起什么作用？

> **答案**。让补丁**在物理世界中真的能用**。现实里补丁会被透视变形、光照变化、缩放、打印失真、运动模糊。如果只针对一帧完美图像优化，一歪就失效。EOT 的做法是**在优化过程中就随机采样各种变换 $t$，并要求补丁在所有变换下都保持有效**，相当于优化一个"对所有歪法都稳健"的补丁。这把一个数字问题转化成了物理鲁棒性问题。

**Q3.** 攻击者拿不到目标模型权重，对抗补丁攻击还可行吗？

> **答案**。**可行**，因为补丁有**迁移性**。在模型 A（或自己的替身模型）上优化的补丁，贴到模型 B 上往往仍然有效——研究显示这一现象源于不同架构共享的高频高显著性脆弱性。书中第 29:275 行的"**筛出在不同模拟器上都稳健的改动**"就是这个思路的实践版：把不同参数的模拟器当作不同模型，**能同时骗过它们的补丁才更可能迁移到真实目标**。当然，迁移不是必然的，模拟器与现实的差距（sim-to-real gap）仍然是最大的不确定性来源。
