# 39 黑盒查询攻击与爬山法（Zeroth-Order / Extremum Seeking）

> 你只有一台黑箱机器，能对它做一件事：输入一个参数，输出一个数字。**没有梯度、没有内部结构、甚至不知道函数长什么样。** 怎么找到让输出最大的参数？——**往各个方向试探，信号会累积，噪声会被时间平均掉。**

## 1. 它是什么

这类方法统称**零阶优化**（zeroth-order optimization）或**无模型优化**（model-free optimization）：

- **零阶**：只用函数**值** $f(x)$，不用导数 $f'(x)$。
- **爬山法 / (1+1) 演化策略**：随机改一点，好就留下、坏就撤销。
- **极值搜索控制**（Extremum Seeking Control, ESC）：控制论里一个 90 多年的经典方法，专门解决"只有标量输出"的最优化问题。

书里第 30 章描述的**正是 ESC 的一个变体**。

## 2. 小说里它在干什么

泽国要骗过北极的视觉 AI，但**拿不到模型权重**。于是他们走了一条完全不同的路。

> 「只怕我们没法用你们的原始权重了……我没法把无人机上那些语言模型的原始权重交给你们。它们受到严密保护，只有极少数人能接触——**正因为担心对手拿到权重去跑梯度下降攻击**。」
> ——第30章，chapter-30.md:9

于是他们改用**北极端子模拟环境的 API 访问权限**。

> 「要有效地训练出对抗攻击，其实并不需要模型的原始权重。」
> ——第30章，chapter-30.md:19

**这是全章的关键断言。** 之后的做法分三层：

**第一层：把二值结果换成标量信号。**

> 「让我们的无人机慢慢靠近目标，看目标需要多久才能发现它。要把侦测时间量出来，这样衡量我们藏得好不好，得到的就是一个**标量信号**，而不只是一个二值结果」
> ——第30章，chapter-30.md:23

**为什么这一步至关重要**：如果只问"发现了没有"（二值），那么**绝大多数查询的结果都是"没发现"**，信号全被噪声淹没。换成"用了多久发现"之后，**每一次查询都带回了连续信息**。

**第二层：爬山法。**

> 「不断朝各个方向对图案做微小改动。凡是能让目标侦测时间变长的改动，就保留下来。这个过程噪声大也没关系，**信号会累积，噪声会随时间被平均掉**。它没有梯度下降那么快，但确实管用。」
> ——第30章，chapter-30.md:25

**第三层：用上自己的权重做混合。**

> 「我们自己也有模型，训练方式和北极的模型相近，而且我们当然握着它们的原始权重。所以我们可以对自己的模型用梯度下降。比如，按我们模拟器里自家模型的判断，**找出10个能把侦测时间拉到最长的最优正交方向**，再把这些方向当作试探性的偏移，拿去他们的模拟器里试他们的模型。同时……」
> ——第30章，chapter-30.md:27

最后是代价：

> 「黑进对手的模拟环境，跑上百万次查询，只为优化几笔随手就能画在纸上的弯曲线条，再骗得对手的无人机把你的无人机当成狗」
> ——第30章，chapter-30.md:105

## 3. 直觉：在浓雾里用指南针（而不是温度计）

- **梯度下降**像"低头看脚下的坡度"——需要地形信息，精准、高效、但**必须有地图**。
- **零阶方法**像"手里只有指南针，不知道山有多高"——只能估方向，慢、糙，但**只要能测量就能走**。

**"正交方向"是什么意思？**

想象你站在平地上，面前是二维参数空间。你不知道往哪走，于是你同时往所有方向轻轻推一点、然后测量：

```
        北 ← 试探
      ↖  ↖  ↖
  西 ← 你 → 东
      ↘  ↘  ↘
        南 → 试探
```

**关键技巧**：不要挨个试，而是**同时试所有方向**，然后测量"哪边被推得更高"。这相当于在每个方向上叠加一个微小的"抖动"信号，再看结果怎么变。

书里说"**10 个最优正交方向**"，就是把这个二维试探推广到 10 维参数空间，且**这 10 个方向互相垂直**——这样它们互不干扰，可以并行估计。

## 4. 原理：ESC 是怎么"看见"梯度的

极值搜索控制的精髓，是**"抖一下，再看平均"**就能测出斜率。

设目标函数 $J(\theta)$，我们只能测量它的值。

**第一步：加抖动（dither）。** 在参数上加一个很小的正弦波：

$$\theta(t) = \hat{\theta} + a\sin(\omega t), \qquad a \ll 1$$

现在被测的输出也跟着轻微波动：$J(\hat\theta) + a\,J'(\hat\theta)\sin(\omega t) + \ldots$

**第二步：解调（demodulate）。** 把输出**乘上同一个正弦波**并在一段时间内取平均：

$$\text{Avg}\big[J(\theta(t)) \cdot \sin(\omega t)\big] \;\approx\; \frac{a}{2} J'(\hat\theta)$$

**这一步是全部魔法所在。** 展开看：任何与 $\sin(\omega t)$ **不同频**的分量（也就是"背景噪声"）在平均后都归零；只有**恰好同频的 $J'$ 那一项**留下了平均值。

> **你从来没有直接测量过 $J'$。你只是"抖了一下，看平均"，梯度就自己浮现出来了。**

用一句话记住：**雪崩检测器（雪崩计数器）就是靠"塞一个测试脉冲，看响应大小"的思路工作的——ESC 是同一个道理，只是把脉冲换成了正弦波。**

**第三步：更新。** 用估计出的梯度更新参数：

$$\hat{\theta} \leftarrow \hat{\theta} - k \cdot \frac{a}{2}J'(\hat{\theta})$$

这就是**梯度下降**——只不过梯度是"测"出来的，不是"算"出来的。

**第四步：正交方向。** 多维情形用不同频率的抖动（$\sin\omega_1 t, \sin\omega_2 t, \ldots$），因为不同频率在时间平均下天然正交；或者用同频率但相位差 90° 的 $\sin$ 与 $\cos$（因 $\text{Avg}[\sin\omega t\cos\omega t] = 0$）。**这正是书里"10 个正交方向"的技术含义。**

**时间尺度分离**是 ESC 能工作的前提：抖动频率 $\omega$ 必须远高于低通滤波截止频率，后者又远高于整体适应速率。**快的东西要滤掉，慢的东西要留下。**

## 5. 关键参数与真实世界

| 参数 | 作用 | 调错了会怎样 |
| --- | --- | --- |
| 抖动幅度 $a$ | 探测强度 | 太小测不准梯度；太大会引入高阶误差 |
| 抖动频率 $\omega$ | 探测速度 | 太慢跟不上环境变化 |
| 低通滤波截止 | 噪声抑制 | 太宽噪声混入；太窄响应滞后 |
| 更新增益 $k$ | 步长 | 太大震荡，太小太慢 |
| 高通滤波 | 去掉偏置 | 去掉目标函数的大尺度慢变分量 |

**为什么需要滤波器**：现实测量总带噪声。ESC 靠**时间平均**抑制随机噪声（书里说的"信号会累积，噪声会随时间被平均掉"就是这个），靠**高通滤波**去掉"设定值漂移"这类与抖动无关的分量。

**ESC 的真实应用领域非常广**：风力发电场的总功率最大化（多个风机各只知道自己的功率，只有总和可测）、换热器网络、油气生产调度、编队飞行、实时自适应巡航控制。**它们的共同特征都是：目标函数不可建模，但只有标量可测。**

**ESC 的重要历史**：这一思想可追溯到 20 世纪上半叶的电机自动调速——**本质上就是一台老式电动机在自动找最佳运行点**。

## 6. 容易误解的地方

**误解一：「零阶方法太笨，能被梯度法完全取代。」**
**不能，因为很多情况下梯度法根本不可用。** 真实场景里：目标函数不可微（离散决策）、没有解析式（复杂仿真）、或者**只有有限权限的黑箱接口**。这时零阶方法是唯一选择。

**误解二：「信号会累积，所以爬山法一定收敛。」**
**不一定。** 爬山法只保证找到**局部**最优。而且书里那句"噪声大也没关系"有前提：**噪声必须零均值、且与信号独立**。如果噪声有系统性偏差（比如模拟器总是高估侦测时间），**信号会被系统性偏移带偏**，优化方向会错。

**误解三：「查到 API 就能算任意函数。」**
**不能。** 零阶方法有一个无法回避的限制：**如果输出本身是离散的（例如"发现了：是/否"），或者被量化、被截断、被限流，你就无法从中恢复梯度。** 书中把"二值结果"换成"标量信号"（chapter-30.md:23）就是绕开这个限制的技巧。**这是零阶方法能否work的分水岭。**

**误解四：「百万次查询不算什么。」**
**很大成本。** 每次查询可能消耗对手的 GPU 算力、可能暴露自己、可能被限流。**所以书中还设计了两层保护**：
- 用**代理端点**中转（chapter-30.md:9、:59）
- 混入**掩护查询**（每次查询同时跑几种不同的攻击，让观测者无法判断真实意图）（chapter-30.md:59）

> 德鲁因的警告很实在：「如果我看得到，他们的哨兵大概也看得到。」
> ——第30章，chapter-30.md:59

**误解五：「用自己家的权重优化就行。」**
不行。书里第 27:275 明说了：

> 「最后的攻击会出现在真实世界里，而不是模拟器里，所以我们能做到的，只是**筛出在不同模拟器上都稳健的改动**。」

**迁移性**——在模拟器上优化出来的攻击，能不能在真实世界里work——是零阶方法最大的不确定性来源。详见 [43 模拟器到现实的差距](43-sim-to-real-gap.md)。

## 7. 自己动手试试

**A. 估算噪声。** 你重复测量同一个参数 100 次，测得值分别是 10、12、8、9、11、10、9、12、8、10……（均值约 10，标准差约 1.5）。
- 平均 10 次后，标准差降到 $\frac{1.5}{\sqrt{10}} \approx 0.47$
- 平均 100 次后，降到 $\frac{1.5}{\sqrt{100}} = 0.15$

**这就是"噪声会随时间被平均掉"的精确含义：标准差按 $\frac{1}{\sqrt{n}}$ 下降。** 要把噪声压到 1/10，需要平均 100 次；压到 1/100，需要 10,000 次。**这就是零阶方法慢的根本原因。**

**B. 手工模拟 (1+1) 爬山法。** 目标函数 $f(x) = -(x-3)^2$（在 $x=3$ 处最大）。从 $x=5$ 出发，步长 0.1，每次随机选 $+0.1$ 或 $-0.1$，若变好就留下。

- $f(5) = -4$；试 $+0.1$ → $x=5.1$，$f = -4.41$（更差，撤销）
- 试 $-0.1$ → $x=4.9$，$f = -3.61$（更好，保留）✓
- 继续类似…

**你需要很多次才爬到 3。** 对比梯度下降一步就到位（$\nabla f = -2(x-3)$，$x=5$ 时梯度为 $-4$，直接朝 3 冲）。**这就是"没有梯度下降快"的定量含义。**

**C. 亲手做一次 ESC 的一维估计。** 设 $J(\theta) = \theta^2$（要最小化），当前 $\hat{\theta} = 3$，抖动幅度 $a = 0.1$，$\omega$ 很高。
- 加抖动：$\theta = 3 + 0.1\sin\omega t$
- 输出：$J = 9 + 0.6\sin\omega t + 0.01\sin^2\omega t$
- 乘以 $\sin\omega t$ 并平均：$\text{Avg}[9\sin] = 0$，$\text{Avg}[0.6\sin^2] = 0.3$，$\text{Avg}[0.01\sin^3] = 0$
- **估计梯度 $= \frac{0.3}{0.05} = 6$**……等等，正确做法是 $\text{Avg}[J\cdot\sin]/(\frac{a}{2}) = 0.3/0.05 = 6$。
- **真实梯度 $= 2\times 3 = 6$** ✓ **完美吻合。**

**请务必亲手算一遍这个。** 它是理解"怎么用标量输出测出梯度"的唯一途径。

## 8. 自测

**Q1.** 为什么必须把"二值发现/未发现"换成"标量的侦测时间"？

> **答案**。因为二值输出几乎全是"未发现"（成功时极其罕见），**绝大多数查询返回同一个值，携带的信息量接近零**。而连续量（侦测时间）**每次查询都带回数值信息**，在扰动下会有系统性的小变化，那个小变化正是我们想测的梯度信号。
> **一句话：二值输出把"信息"截断成了"成功/失败"，而零阶方法需要连续的小变化才能做平均。** 这是零阶优化能否work的分水岭。

**Q2.** ESC 怎么用"只有输出值"测出梯度？

> **答案**。四步。①在输入上加一个很小的正弦抖动 $a\sin\omega t$；②测量输出的波动；③把输出**乘以同一个正弦波**并做时间平均——与 $\sin\omega t$ 不同频的成分（背景噪声、漂移）平均后归零，只有同频的梯度项留下 $\frac{a}{2}J'$；④用这个估计值更新参数。
> **核心是"乘上同一个抖动再平均"——这是一个把频率当作滤波器、把梯度当作"与抖动同频的分量"提取出来的过程。**

**Q3.** 书里第 27:275 说"筛出在不同模拟器上都稳健的改动"。为什么必须这样做？

> **答案**。因为攻击最终要作用在**真实世界**，而我们只能在**模拟器**上优化。模拟器与现实之间存在**分布差异**（sim-to-real gap，见 [43](43-sim-to-real-gap.md)）。只在某一个模拟器上取得最优的改动，很可能只利用了那个模拟器的**特有缺陷**，到了真实环境就失效——这叫**过拟合到模拟器**。
> 在**多个不同架构的模拟器**上都有效的改动，才更可能抓住了**不同模拟器共享的弱点**（即目标模型本身共有的脆弱性），因而更可能迁移到现实。**这是"稳健性即泛化"思想在对抗攻击里的体现。**
