# Snowmoon / 雪月 · 中文版

本项目为 [Vitalik 的小说 Snowmoon](https://vitalik.eth.limo/snowmoon/) 的非官方中译版本（之一），
目标是译制为更适合中国宝宝体质的小说阅读形式。

原著共 32 章、约 10.4 万英文词，正文内嵌约 180 幅 SVG 插图。

## 依赖

| 用途 | 依赖 |
| --- | --- |
| 阅读成品 | 现代浏览器，无需构建 |
| 文字译制 | DeepSeek Harness + DeepSeek V4.1 Flash |
| 图片生成 |视觉模型|
