关于这本书

《雪月》是 Vitalik Buterin 创作的一部带有太阳朋克色彩的英文科幻小说。 故事中的城邦维里迪亚（Veridia）、密码学投票、 手表终端与虚构语言 Dzegoban， 共同构成了一个值得缓慢探索的未来世界。

这里收录已完成的中文译本，共 32 章、约 14.6 万 汉字， 配有 56 幅中文重绘插图，并保留故事中的模拟手表与终端界面。 本站是非官方译本，未经原作者审定；对译文有疑问时，欢迎对照英文原文。

为长篇阅读留出空间

按你的习惯阅读

默认中文单栏。进入正文后，可在「阅读设置」中调整排版与阅读方式。

中文、英文与对照

随时切换中文、English 或中英对照。空间充足时，英文在左、中文在右， 两栏独立滚动并默认按进度同步；空间不足时自动切为中文与英文标签页。

纸张底色，也有深夜灯光

羊皮纸、浅色、深色与夜间护眼主题，搭配五档字号、三档行距、 宋体与黑体两套系统字体，以及「常规段落 / 一句一行」两种中文段式。

向下滚动，或左右翻页

默认上下滚动，也可切换左右分页。正文提供上一章、下一章和快捷目录； 点击正文中部可收起菜单，让注意力回到文字。

替你留住上次的位置

章节位置与阅读设置保存在当前浏览器本地，不上传、不跨设备同步。 清除浏览器数据会移除记录；若本地存储不可用，仍可正常阅读。

无需登录，无广告。关闭 JavaScript 后，仍可阅读完整中文正文，并通过目录与章节链接浏览全书。
