# 第二十四章

<p class="dateline">帕佛盖都，泽国 · 3724年雾期27日</p>

格拉迪亚斯看了一眼手表。时间刚跳到20,000。和塞拉通完电话后，他一整夜都没睡。他试了两次去睡，每次都撑了20分钟就放弃了。

他睡不着。4个他深爱的孩子里，已经有3个以这样那样的方式落进了北极人手里——他知道这一点。

他也睡不着。塞拉投了他一张不信任票，切断联系，连让他道歉的机会都不给。

他更睡不着。两件事同时压在他身上，能让他抱一抱、讨点安慰的人又在几千公里之外。

最后，他既想着女儿的安全，也想着在塞拉眼里挽回自己，于是决定做一件不合常规的事：他打给了兹文。

兹文立刻就接了。

<span style="color:#df74b1">“爸？”</span>

<span style="color:#be9b00">“你还在和莉莉联系吗？”</span>

<span style="color:#df74b1">“她的头像40分钟前变绿了。我想她是用新设备登录的。”</span>

<span style="color:#be9b00">“好。”</span>

<span style="color:#be9b00">“兹文，你愿意帮我们把莉莉救回来吗？”</span>

<span style="color:#df74b1">“当然！为了我妹妹，什么都行。”</span>

<span style="color:#be9b00">“那接下来，我要你做这么几件事。跟她保持联系。主动找她，问问她最近怎么样。别流露出半点不赞同她决定的意思，甚至要表现出同情。总之保持联系，想办法弄清她在哪儿。”</span>

<span style="color:#df74b1">“爸……”</span>

<span style="color:#be9b00">“怎么了？”</span>

<span style="color:#df74b1">“这简直……跟妈妈一个长时前让我做的一模一样。她还教了我很多该说和不该说的话。”</span>

---

格拉迪亚斯打开门，穿过走廊，走出酒店区域，然后左转，继续沿隧道往前走。

到今天，他住在地下已经整整8天，就住在帕佛盖都南端的山体金字塔里。他刚到泽国不久，就被安排从原先的酒店搬到了这里。新出台的建议是让所有“重要事务”一律转入地下，而格拉迪亚斯作为事实上的昆高培顾问，当然够格。

两个多月来，他每天都沿着山体金字塔半山腰的环山树林散步20分钟，有时还会往下走得更远，进到附近的森林里。最近这些天，他白天都待在图书馆，了解泽国的方方面面，几乎每天都和韦尔多通话，琢磨怎么说服维里迪亚军方与昆高培合作。

而今天，经历了昨晚那些事，又只睡了一个长时，他连出门的力气都提不起来了。

格拉迪亚斯走得很慢，去图书馆的路上常常停下，盯着墙面，或是打量经过的侧边房间。

他注意到，自他搬进来以后，各类高科技产业——生物医药、芯片制造，甚至汽车生产的一部分——都迁进了山体金字塔。再一琢磨，自从北林被吞并之后，新闻里就再没出现过一起北极对泽国的成功袭击。

他还注意到，散落各处的空气过滤器和紫外线灯多了10倍以上。至少泽国的厂商和班孙培干得不错，他想。

他经过一间食堂的入口，看见里面多了几棵树，种在陶盆里，约两米高，还摆着各色灌木。这些绿植似乎身兼三职：让坐在里面的人看着绿意心生平静，降低 CO2 浓度，还把食堂的不同区域隔开，多一分私密。

慢吞吞走了大约15分钟，他终于来到图书馆门口。

他发现门楣上的标语和上次来时不一样了。

他停下脚步，花了一会儿工夫读那行字。

“学生说：明天，我想去一个神奇而遥远的地方。老师答道：为了明天，你今天做了什么？”

让格拉迪亚斯意外的是，这句训诫给了他一点力气，让他能抬手贴上绿色圆圈开门，走进图书馆。

他穿过门，慢慢向右转，朝其中一台计算机终端走去。

白注意到了他，走上前来。

<span style="color:#ed756b">“怎么了？”</span>她问。

<span style="color:#be9b00">“我没事”</span>，格拉迪亚斯用低沉而平淡的语气答道。

<span style="color:#ed756b">“不过，我了解得够多，看得出你心里并不好受。我也知道，如果你不情愿，还逼你说出心里那片阴影的来由，只会让你更难受。”</span>

<span style="color:#ed756b">“所以别担心，我什么都不会问。”</span>

她走到格拉迪亚斯面前，轻轻抱住了他。

<span style="color:#be9b00">“我刚刚才得知，莉莉这一年来对北极的宣传全盘接受，而埃菲里昂勋爵的布道让她觉得自己被重视、被欣赏，比我给她的多得多。不到一分钟，我又得知她离家出走了。又过一分钟，我得知塞拉现在恨我，不想跟我说话。”</span>

<span style="color:#ed756b">“北极人说的那些话里，有哪些能让像她这样的人觉得有说服力？”</span>

<span style="color:#be9b00">“无条件的爱毫无意义。爱只有在你爱对方身上某种品质时才值钱。所以要得到爱，你就得配得上它，得去挣。爱不能像恒定的背景辐射那样白白照着你，只能是赢来的奖赏。”</span>

<span style="color:#be9b00">“最重要的是永远努力提升自己。可如果你能提升，就说明你能比过去的自己更好——那你就等于承认了，一个人可以比另一个人更好。所以，说什么我们人人平等、说什么我们身上最重要的是那份平等的人性——全是胡说。”</span>

<span style="color:#ed756b">“你知道……我其实有点同意。”</span>

<span style="color:#be9b00">“什么？”</span>

<span style="color:#ed756b">“我不是说在什么绝对意义上，这种想法对每个人都健康。绝对不是。要是你真觉得它健康，那当然，一旦你认定自己最强，就会想去征服所有人，只为了证明这一点。我的意思是……这种想法对我有好处。”</span>

<span style="color:#be9b00">“你是什么意思？”</span>

<span style="color:#ed756b">“我父母在我很小的时候就死了。一场爆炸，北极人引发的。我跟着姨妈长大，她基本上不管我。没有人无条件地爱我。我12岁就得自己想办法挣钱。我的社交能力全是从那段经历里学来的。我从别人那里得到的唯一欣赏，就是在我给他们提供了有价值的东西、或者用成功让他们佩服的时候。你说的埃菲里昂那套循环——爱是赢来的奖赏——那就是我的童年。也正因为这样，我在帕佛盖都民本棋赛上拿了第二名。”</span>

<span style="color:#be9b00">“第一名是谁？”</span>

<span style="color:#ed756b">“泽。而他要赢的动机，比我那种要向世界证明‘我因为强，所以值得被爱’的求胜心，还要更纯粹、更漂亮。”</span>

<span style="color:#be9b00">“那是什么动机？”</span>

<span style="color:#ed756b">“好奇。”</span>

对话停了一会儿。然后格拉迪亚斯又开口了。

<span style="color:#be9b00">“几分钟前你抱我的时候，你给的难道不正是埃菲里昂说的那种毒药吗？把爱当作对软弱的奖赏？”</span>

<span style="color:#ed756b">“一年前我不会那么做。”</span>

<span style="color:#be9b00">“可它管用了。”</span>

<span style="color:#ed756b">“我很想说，我那么做是因为我抛弃了贪婪这个假神，改信了真正的宗教——看重好奇。可连这也是假的。如果我是出于好奇，我大概会直接问你出了什么事，而那只会惹你反感。”</span>

<span style="color:#be9b00">“那倒是肯定的。”</span>

<span style="color:#be9b00">“所以你的结论是什么？”</span>

<span style="color:#ed756b">“也许真的没有什么万能公式。不同的人适用不同的招数。我不会说我对人类可能有的各种动机全都无所谓——我今天可以很坦然地说，好奇几乎总是比贪婪更好的动机。而怨恨可能是最糟的。但我不认为有哪一套能适合所有人。”</span>

<span style="color:#be9b00">“那我要怎么救莉莉？还有，费布里克和赫雷达呢？还有，我怎么才能让塞拉不再恨我？”</span>

<span style="color:#ed756b">“嗯，也许这正是你唯一需要变得至少有10%到20%像北极人的地方。如果我们能赢，你的家人就能完完整整地重聚。你从塞拉的角度想一想。她唯一能快乐的办法，就是能再抱一抱费布里克、赫雷达和莉莉。可光靠情感支撑和爱，没有任何办法把这3个人带回来。唯一**能**把他们带回来的，就是你赢——帮维里迪亚战胜北极人。所以，让这件事推着你更拼命一点，好让你在下一场战斗里成为赢家。”</span>

---

格拉迪亚斯和泽沿隧道往下走，又下了楼梯。几分钟后，他们来到一扇密封的门前。泽把手表贴上门边的绿色圆圈。门缓缓打开了。

他们看见一个狭长的房间，房间尽头有一张大桌子。桌边坐着一个男人，披着一件暗影般的斗篷。

<span style="color:#e58137">“欢迎你们两位！”</span>登高声说。

<span style="color:#df74b1">“很高兴再见到你，登。”</span>泽答道。

格拉迪亚斯清了清嗓子。<span style="color:#be9b00">“mi cin pin fe lo kin do”</span>，他补了一句。

<span style="color:#e58137">“哇，你的口音现在都这么好了。我也很高兴见到你，格拉迪亚斯。”</span>

<span style="color:#e58137">“对了，请坐。”</span>

格拉迪亚斯和泽一起上前，在登对面的两把椅子上坐下。

<span style="color:#e58137">“那么，格拉迪亚斯。这次会面是你召集的。你想谈什么？”</span>

<span style="color:#be9b00">“嗯，到目前为止，我们还没想出什么好办法，能说服维里迪亚军方与你们合作。”</span>

<span style="color:#be9b00">“不过，我倒有个不太常规的想法，可以让你们在过渡期里先做起来。”</span>

<span style="color:#e58137">“什么想法？”</span>

<span style="color:#be9b00">“监视我们。”</span>

登有些意外地看了格拉迪亚斯一眼，几乎立刻又恢复了平静，仿佛这才想起：公开流露兴奋或其他计划外的情绪，与他的自我形象不符。

<span style="color:#e58137">“我想我能看出其中的道理。不过我想听你说。”</span>

<span style="color:#be9b00">“北极人对维里迪亚社会的渗透非常深。他们腐蚀了许多政客，也腐蚀了军方。似乎只有那些内建隐私保护更强的机构还在抵抗：掌舵会、图谱资助和合议庭。不过即便在掌舵会内部，渗透也已经钻得很深。”</span>

<span style="color:#be9b00">“所以，如果你们能监视维里迪亚，也许就能监视那些间谍。尽可能查清北极人对维里迪亚的渗透落在哪里，甚至试着反制。也许还可以把这些信息更直接地交到人们手里，让他们不必经过中央机构就能自己去解决。”</span>

<span style="color:#e58137">“你知道风险吧？”</span>

<span style="color:#be9b00">“如果你们被抓住，维里迪亚和泽国之间的信任会大打折扣。那样我们就彻底分裂，北极人赢了。”</span>

<span style="color:#e58137">“那我们凭什么该接受这个风险？”</span>

<span style="color:#be9b00">“嗯，首先，这局棋我们已经下到很后面了，局面很绝望。用你或者泽的话说，第九次干预回合。”</span>

<span style="color:#be9b00">“第二，我不是只丢给你们一句‘去当间谍’就完了。我愿意提供关于北极人如何运作的许多具体细节，也能帮你们搭上我们最近联系上的一批掌则人，好让你们能更好地追踪北极人。”</span>

<span style="color:#be9b00">“第三，我觉得我们应该告诉韦尔多，说服他和我一起担起责任：万一这事泄露出去，由我们两个人出面认下，说项目是我们提的，甚至是我们主持的。”</span>

<span style="color:#e58137">“我喜欢这个方案。泽？”</span>

<span style="color:#df74b1">“你在问我？”</span>

<span style="color:#e58137">“当然。你已经是我们最好的密码学家之一，还一直在协调与自由城防卫队的合作。你觉得呢？”</span>

<span style="color:#df74b1">“十五年来，数字设备上的安全一直非常牢固。间谍活动主要是物理世界的事，而物理世界要守住难得多。我觉得应该带格拉迪亚斯去看看一些店铺和晶圆厂，比如你很久以前带我看过的那家，然后我们可以一起想，有什么不太惹眼的办法能弄到更多关于维里迪亚的情报。”</span>

<span style="color:#be9b00">“其实……我记得维里迪亚的监控摄像头是从泽国买的。就是已经装在不少地方、他们还想装到所有地方的那种。维里迪亚过去要求，摄像头装在公共场所时，必须用密码学手段强制执行数据用途限制，但几年前这一条被稀释了，是交通部一次没人注意的行政调整。你们能不能就……给那些摄像头留个后门？”</span>

<span style="color:#e58137">“如果真有这么容易，那北极人肯定早就大规模渗透维里迪亚了吧？”</span>

<span style="color:#be9b00">“是啊，怎么了？”</span>

<span style="color:#e58137">“已经渗透了吗？”</span>

<span style="color:#be9b00">“是啊，这一直就是我想告诉你们的啊！”</span>
