# 第二十章

<p class="dateline">梅尔丹，维里迪亚 · 3724年雾期10日</p>

手表的闹钟震了震，塞拉醒了。表盘正闪着刺眼的红光——那是翡翠发来的消息，她从来没见过这种类型。

她立刻坐起身，打开手持终端，想看清新闻的更多细节。

看到最上面那行字时，她的心脏几乎停跳。

<blockquote><p>北极帝国入侵北林</p></blockquote>

北林。费布里克和赫雷达就在那里。不……

她继续往下读。

<blockquote><p>今天早上5,250时，北极士兵、飞行器和无人机从四面八方扑向北岸省。</p><p>维里迪亚军队几乎没有抵抗，两个长时之内，北极的士兵和无人机就已驻扎在北林。</p><p>目前整个地区已完全落入北极控制，只有一个例外。北林境内的大梅港始终未被北极人触碰，眼下似乎被当作某种中立区受到尊重。数百名难民涌入大梅港，随后北极人架起路障，阻断更多入口。还有更多难民试图乘个人飞行器进入，约半数成功，尤其是在第一个长时里，其余的则被击落。</p><p>北林与维里迪亚其他地区之间的网络通信已被切断，只有大梅港例外。大梅港与北林其余地区之间的远距离传输躲过了干扰无人机制，如今成了与北岸省双向通信的主要通道。</p><p>北岸的地方政客和北极官员都还没有发表任何公开评论。据我们最后掌握的消息，入侵发生时，北极驻维里迪亚领事埃菲里昂勋爵正在北林。我们等待进一步消息。</p></blockquote>

她向下滑动手持终端，看到翡翠还标出了另外五条它认为对她非常重要的消息。

塞拉开始回消息，向费布里克和赫雷达确认自己收到了他们的消息，并说她和维尔、黛雅会尽一切努力把他们接回家。还没打完，她就哭了。

---

一个长时后，她听见有人敲门。她走到门口，透过屏幕看见外面站着一个穿隐私袍的男人。

<span style="color:#54a1f9">“你是谁？”</span>她问。

<span style="color:#00bc96">“我是莫夫。格拉迪亚斯跟我很熟。”</span>

<span style="color:#54a1f9">“我凭什么相信你？”</span>

男人对着颈带低声说了几句，又把手持终端贴到房子门旁的绿色圆圈上。塞拉的手表震了一下。

<div class="device-view narrow-device-view"><div style="border: 1px solid; border-radius: 5px; padding: 5px"><b>格拉迪亚斯的常用联系人<br><br>证明已验证</b><b style="font-size: 150%; color: #8f8">✓</b></div></div>

塞拉小心地打开门，让男人进来。

莫夫脱下鞋，径直走向地下室那个房间，对这栋房子里的位置一清二楚。塞拉跟在他后面。

两人坐下。

<span style="color:#00bc96">“维里迪亚发生的这些事，让我非常不安。”</span>

塞拉面无表情地看着他，惊讶于这么明摆着的事他居然也说得出口。

<span style="color:#00bc96">“我不是说北林被入侵这件事。那的确骇人，太糟了。费布里克和赫雷达在那里，我真的很抱歉。希望他们平安。”</span>

<span style="color:#54a1f9">“他们没事。北极人不知为何放过了大梅港，费布里克和赫雷达及时赶了进去。”</span>

<span style="color:#54a1f9">“那你想说什么？”</span>

<span style="color:#00bc96">“我是说让这场入侵得以发生、还能几乎不受抵抗就成功的那些东西。那些因素在维里迪亚其他地方同样存在。”</span>

<span style="color:#00bc96">“平时我该找格拉迪亚斯谈这些，但这几天他一直忙着跟泽国秘密政府的人开会，过去几个长时都在睡觉。所以我想跟你谈谈。”</span>

<span style="color:#54a1f9">“你觉得我知道什么？我们的政客显然不是被收买，就是被要挟，再不然就是麻木不仁，或者三样都占一点。格拉迪亚斯很少跟我谈掌舵会的事，毕竟他本就不该谈。”</span>

<span style="color:#00bc96">“那我把我知道的告诉你吧。我一直在跟踪德尔瓦特——过去几个月里频繁跟格拉迪亚斯见面的那位神秘先生。他不只跟格拉迪亚斯谈，还在跟另外好几位掌则人谈，人脉似乎铺得相当广。”</span>

<span style="color:#00bc96">“有一次，在我跟丢他之前，我撞见他跟银聊的人见面。后来格拉迪亚斯告诉我，他跟德尔瓦特对质过，德尔瓦特承认自己一直在为银聊做事。”</span>

<span style="color:#54a1f9">“银聊？他们在搞什么大动作，要腐蚀掌舵会？可为什么？这种事我以为是蓝鲸干的，银聊一直是好人那边！这又跟北极人有什么关系？”</span>

<span style="color:#00bc96">“我觉得我们这个社会只是太安逸了。人人都只顾维持自己的快活日子，能占一点便宜就占，没人真在乎去维护那些让维里迪亚运转下去的东西。连银聊也一样。更糟的是，掌则人似乎根本没在防这件事。”</span>

<span style="color:#54a1f9">“跟我们其他机构相比，掌舵会看起来做得最好。军队在北岸的防御部署彻底失败。据我看，掌则人已经尽了力，税则甚至改得更支持开源防御硬件了，这是格拉迪亚斯告诉我的。他为此很自豪，我也是。”</span>

<span style="color:#00bc96">“确实，不过那也是险胜。把掌则人分成三个互不通信的小组的那个人真是天才——否则德尔瓦特可能已经把他们都拿下了。”</span>

<span style="color:#54a1f9">“这事有哪里不对劲。银聊……他们不像是会做这种事的人。”</span>

<span style="color:#00bc96">“我知道你从小就一直喜欢他们，跟格拉迪亚斯当年一样。我也是。可有时候……你的英雄未必真是英雄。又或者银聊压根不在乎那条评则，那只是德尔瓦特自己是个极端的和平鸽。”</span>

<span style="color:#54a1f9">“德尔瓦特接触过的其他掌则人，你认识吗？我们能找其中谁谈谈吗？”</span>

<span style="color:#00bc96">“我确实在其中两个人身上放了追踪器。我完全可以把他们举报给密码学网络，拿一大笔赏金，但……我想留着继续跟踪他们的余地更好。”</span>

<span style="color:#54a1f9">“我们能跟他们谈谈吗？”</span>

<span style="color:#00bc96">“可以吧。”</span>

<span style="color:#54a1f9">“我们去见他们。就现在。”</span>

<span style="color:#00bc96">“你今天不想先看看自己能替费布里克和赫雷达做点什么吗？”</span>

<span style="color:#54a1f9">“我也许是个操心的妈——呃，好吧，是婶婶——但我知道我能做的并不多。我已经跟他们通过话了，他们按兵不动，我也按兵不动。想从北林搞一场什么大逃亡，我不觉得我们和他们能比那上百个想飞进大梅港却被击落的人强。所以，按兵不动就是计划，今天没别的可做。但弄清掌舵会到底出了什么事，这是我今天能做的。”</span>

她叹了口气。

<span style="color:#54a1f9">“我大概就是觉得，我必须得做点什么，而这正是我能做的。”</span>

莫夫点头。

<span style="color:#00bc96">“别坐小型飞行器。你可能觉得它更快，这一次那高得离谱的噪音税也值了，但那只会给自己招来注意。”</span>

<span style="color:#54a1f9">“放心，我没打算坐。”</span>

一辆出租车到了。塞拉披上一件格拉迪亚斯的隐私袍。她和早已穿着隐私袍的莫夫快步走向出租车。塞拉先到门边，把手表贴上车门旁的绿色圆圈，门应声打开，付款也同时通过了密码学验证。两人上了车。

出租车开动了，目的地离另一位掌则人的家只有一小段巴士车程。

---

二十分钟后，他们来到一栋公寓楼前。楼是新建的，外墙裹着某种仿石材。一层能看到餐馆和卖各类商品的店铺。楼层再往上，从外面只能看见一扇扇住户的窗户，间距规整，装点得也挺讲究。

他们看见另一个男人正走向楼门，准备进去。两人立刻放慢脚步，好显得自然而然地跟在男人后面进门。

男人走到门前，把手表贴上旁边的绿色圆圈，门开了。他走了进去。门还没合上，塞拉和莫夫也跟了进去。

<span style="color:#00bc96">“他在515号房，”</span>莫夫说，<span style="color:#00bc96">“我们走楼梯上去吧。”</span>

<span style="color:#54a1f9">“你怎么知道的？”</span>

<span style="color:#00bc96">“我放他身上的追踪器。”</span>

两人沿楼梯往上走，最后来到515号房门前，敲了敲门。

门里传来脚步声。莫夫摘下隐私袍的兜帽，这个动作是想显得没那么有威胁。他本不该认识这个人，所以没法证明自己是值得一谈的人——除非在他门口烧掉100齐普币。塞拉也摘下了兜帽。

男人干脆把门打开了。

<span style="color:#7499fb">“你好？”</span>

<span style="color:#54a1f9">“你好，我是塞拉。我知道这样很唐突，但我们想谈谈掌舵会和德尔瓦特。”</span>

男人瞪大了眼睛。

<span style="color:#7499fb">“幸会，塞拉。”</span>

<span style="color:#00bc96">“我是莫夫。”</span>

<span style="color:#7499fb">“我是特尔罗伊。不过……既然你们知道我在掌舵会，也知道德尔瓦特的事，那也许我是谁，你们也早就知道了。”</span>

那一刻莫夫意识到，从某种意义上说，他在特尔罗伊门口烧掉的早已远超100齐普币——他手里的信息足够让他把特尔罗伊的角色举报给掌舵会的密码学网络、领一大笔赏金，而他选择了不这么做。

莫夫和塞拉走了进去。特尔罗伊请他们在沙发上坐下，然后开始给三个人泡茶。

<span style="color:#7499fb">“那关于我和德尔瓦特，你们都知道些什么？”</span>

<span style="color:#00bc96">“你是掌则人，在网络安全评则组。你们正在讨论的一条评则跟环境传感器的数据留存有关。你至少见过德尔瓦特一次，只是我没能听到你们谈话的内容。”</span>

<span style="color:#7499fb">“好吧，你们确实知道不少。德尔瓦特在跟我谈话时一直坚持说，最近那波尽量少收集数据的推动其实没有道理，那有点疑神疑鬼，防的是一个根本不存在的敌人——不过也许现在他会改口了。他跟我说，更需要防的信息威胁其实是内幕交易。”</span>

<span style="color:#7499fb">“他还说，地方的环境与公共安全机构需要广泛的访问权限，才能在情况变化时迅速应对，不必每次都申请许可——而我们真正需要的主要隐私防线，是把他们获取与疾病无关数据的时间推迟五到十天，这样他们就没法拿它去做交易。”</span>

<span style="color:#54a1f9">“这……跟格拉迪亚斯告诉我的德尔瓦特完全不像。”</span>

<span style="color:#00bc96">“他还说了别的吗？”</span>

<span style="color:#7499fb">“就像我说的，他总体上反战——这是他自己的说法。除此以外没太多别的——他的主要看法是，他觉得人们把事情搞得太复杂，硬要塞进各种密码学，我们应该多信任人一些。”</span>

<span style="color:#7499fb">“好，那我倒好奇了——你们认识的德尔瓦特是什么样？”</span>

<span style="color:#00bc96">“他反战。他看重人们按自己方式生活的自由，他希望掌舵会少管很多——连税收引导他都嫌多。不过特别要说的是，他极力反对税则的这一项改动——”</span>

莫夫停住了。他意识到塞拉已经主动说出了格拉迪亚斯的名字，如果自己再说下去，可能就是在给特尔罗伊提供线索，让他能推断出格拉迪亚斯的评则，然后靠举报他领赏金。

但他又想——特尔罗伊信任他和塞拉，他们至少也该回报一点信任。

<span style="color:#00bc96">“开源硬件那条评则。他认为任何与军事相关的东西都该排除在税收优惠之外，因为军事是零和博弈，我们参与进去对世界没有任何好处。”</span>

特尔罗伊点头。<span style="color:#7499fb">“那他确实是真的反战。”</span>

<span style="color:#00bc96">“但后来我又跟了他一阵，红郡被入侵之后格拉迪亚斯跟他当面对质，结果……他一直在为银聊做事。”</span>

特尔罗伊惊讶地瞪着眼。<span style="color:#7499fb">“银聊？”</span>

<span style="color:#7499fb">“这……真让人意外。”</span>

---

塞拉和莫夫下了出租车，沿着卡利马尔林间的步道走。一阵微凉的清风拂过他们的后背，不知不觉催着他们加快了脚步。走了几百米，他们离开步道向右转。又走了三十米，他们看见一栋大部分埋在地下的石屋，露出地面的部分只有一米高。从几米开外，几乎看不出这里还有建筑。

她心想，这倒是个在美学、公共通行和应急避难功能上同时拿高分的办法。这栋房子大概几乎不用交土地税。

塞拉和莫夫沿楼梯走下去，敲了敲门，然后摘下隐私袍的兜帽。

里面传来脚步声。

<span style="color:#ed756b">“谁啊？”</span>他们听见一个女人的声音问。

塞拉悄悄踩了一下莫夫的脚，示意他别出声。莫夫会意，退后一步。

<span style="color:#54a1f9">“你好，我是塞拉。我知道这样很唐突，但我们想谈谈掌舵会和德尔瓦特。”</span>

门立刻开了。

<span style="color:#ed756b">“你好，我是巴尔梅。请进。”</span>

<span style="color:#54a1f9">“我朋友莫夫也一起进来，可以吗？”</span>

塞拉察觉到巴尔梅有些不安——现在是二对一，莫夫的体格又更高大、更有压迫感——但那时她已经把门打开了，再把门关上至少也会非常尴尬。

<span style="color:#ed756b">“好。”</span>她轻声答道。

塞拉和莫夫都进了门。

<span style="color:#00bc96">“很抱歉这样粗鲁地闯进来，还跟踪你查到了地址。但希望你能原谅我；如你所见，我们的国家处境相当糟糕。”</span>

巴尔梅点点头。

<span style="color:#54a1f9">“关于德尔瓦特，你知道些什么？”</span>

<span style="color:#ed756b">“我见过他几次。第一次交谈是在一次掌则人会议后大约一个长时，他给我发了一封匿名消息。他不知怎么找到了我。我在私立学校评则组。他谈了很多自己对教育的看法，说我们不该把拇指按在天平上，用税则去鼓励他所认为有偏向的公民课——讲维里迪亚多么美丽，教学生珍惜和热爱它——他认为学校只该教人知识；至于爱不爱维里迪亚，该让他们自己看到它有多好，然后自己去爱上它。”</span>

<span style="color:#54a1f9">“他还有别的观点吗？”</span>

<span style="color:#ed756b">“他大体上是倾向自由的，认为该让人自己去摸索、慢慢发展；事情顺其自然往往结果最好，掌舵会不该这样把拇指按在天平上。”</span>

<span style="color:#54a1f9">“有没有谈到国际政治？”</span>

<span style="color:#ed756b">“基本没有，他从没提过。他似乎并不关心。”</span>

<span style="color:#ed756b">“不过他有一次问过我怎么看恐结。我回答说我不太喜欢他们。他没接话，换了话题。”</span>

塞拉点点头。

<span style="color:#54a1f9">“我认识的德尔瓦特同样在意自由，同样认为掌舵会该少管很多。但……他对国际政治也有很强的看法。他基本上认为军事就是零和博弈，你没法预知哪一步会带来好结果、哪一步会带来坏结果，维里迪亚就该完全置身事外。”</span>

<span style="color:#54a1f9">“不过……他在自由这件事上似乎又比较矛盾。他似乎觉得公共安全机构多收集信息也无所谓，不必用密码学去限制数据收集、去要求对方保证数据只用在什么地方。”</span>

巴尔梅惊讶地睁大了眼睛。

<span style="color:#ed756b">“等等，我好奇，密码学怎么能做到那个？”</span>

<span style="color:#54a1f9">“我有个泽国的朋友叫泽，跟我讲过一次。大概就是在摄像头里装一个语言模型，用来判断——比方说——有没有正在发生的暴力行为。只有真的发生了，它才把信息传出去。每次传出，它还会把一个哈希上传到密码学网络，这样我们就能公开查到这项检查一共被触发过多少次。”</span>

<span style="color:#54a1f9">“而且他们有一整套基础设施，来验证硬件确实在运行那段代码。签名所用的密钥，是在芯片制造时由化学瑕疵在芯片内部随机生成的。据说还有一条规则：任何人都有权随机拆下一台摄像头做微观检查，很多人把这事当爱好在做，所以没有厂商能靠造出作弊的摄像头蒙混过去。”</span>

<span style="color:#ed756b">“这……听起来太厉害了。密码学完全不是我的领域，但……真正能信任的摄像头，这太说得通了！可等等，德尔瓦特那么主张自由，他怎么会不知道这类东西，还不为它兴奋呢？”</span>

<span style="color:#54a1f9">“我也想不通。”</span>

塞拉停顿了片刻。

<span style="color:#54a1f9">“好，我知道这问题问得没头没脑，不过——你认识哪个掌则人是在社交媒体相关评则组里的吗？”</span>

<span style="color:#ed756b">“我认识几位掌则人朋友，但我不敢问他们在做什么。这是我们的传统：只有等你做满三年、换到别的评则组之后，才能公开谈自己做过的事。”</span>

<span style="color:#54a1f9">“你能不能……帮我给他们转一条消息？我现在就写给你。再告诉他们，这条值得回。”</span>

巴尔梅想了想，在心里掂量塞拉——还有她那个至今一言未发的朋友——是否可信。直觉告诉她，可以信。

<span style="color:#ed756b">“当然。”</span>

塞拉走到一栋房子门前，那房子和她与格拉迪亚斯住的那栋很像。这一次，莫夫完全留在后面。他觉得塞拉独自一人似乎更容易赢得信任，索性让她自己去问。需要的话，他可以通过耳机提示该问什么。

塞拉敲了敲门。

没有回应。

一分钟后，她又敲了一次。

仍然没有回应。

她听见里面有脚步声，但似乎并没有朝门口靠近。

她的手表震了一下。她收到一条通知：

莫夫……她心想。她知道屋里的人也会收到同一条消息，并明白她是认真的。

塞拉第三次敲门。

她又听见脚步声，这次是朝门口来的。

<span style="color:#23ba7d">“你想干什么？”</span>

<span style="color:#54a1f9">“你好，我是塞拉。就是我请巴尔梅和特尔罗伊转那条关于社交媒体评则的消息。我想谈谈。”</span>

男人打开了门。

<span style="color:#23ba7d">“我是莱克托比。我在社交媒体开放度评则组。”</span>

<span style="color:#23ba7d">“抱歉我没开门。我妻子困在北林。我今天心情糟透了，就是不想跟人说话。”</span>

塞拉点点头。

<span style="color:#54a1f9">“我是塞拉。我理解。我的孩子也困在北林。”</span>

<span style="color:#23ba7d">“你为什么要烧那些齐普币？你直接让巴尔梅告诉我你要来就行了。”</span>

莫夫……塞拉在心里恼火地想。他为什么非要这么没耐心？

<span style="color:#54a1f9">“抱歉，我实在走投无路了。”</span>

莱克托比示意塞拉进来，她跟了进去。两人坐下。

<span style="color:#23ba7d">“那这是为了什么事？”</span>

<span style="color:#54a1f9">“过去一年左右，有没有什么陌生男人试图联系你，或者你认识的评则组里的其他人？”</span>

<span style="color:#23ba7d">“嗯……没有，没听说过这种事。”</span>

<span style="color:#54a1f9">“你能不能……直接在你们评则组的群里问一下？我想确认。”</span>

<span style="color:#23ba7d">“你遇到过这种事吗？”</span>

<span style="color:#54a1f9">“我丈夫遇到过。巴尔梅也是。还有不少人。他的看法很鲜明，而且似乎见什么人说什么话。有时他反战，有时不反。有时他反对掌舵会干预任何事，有时又不反对。”</span>

莱克托比对着颈带低声说了几句。

<span style="color:#23ba7d">“先看看我那个掌则人小组怎么说。”</span>

他站起身。

<span style="color:#23ba7d">“要喝点茶吗？”</span>

<span style="color:#54a1f9">“好。”</span>

莱克托比走到厨房，给自己和塞拉烧水。

<span style="color:#23ba7d">“孩子的事，我很遗憾。北极这一摊事真是……太疯了。先是红郡，现在又是这里。感觉他们正在换挡提速，一两年之内就会直接发动一场大战，把整个世界都吞下。”</span>

<span style="color:#54a1f9">“或者更糟，不到一年。他们拿下了北林，看起来又没见谁动一根手指。来的路上我看了一下参议院听证会，满场都是作秀式的义愤，没有行动，也没有反思我们是怎么走到这一步的。”</span>

莱克托比叹了口气。

他给自己端来一杯茶，又给塞拉端来一杯，两人坐下，默默喝着。

<span style="color:#23ba7d">“他们都回了。”</span>他说。

<span style="color:#23ba7d">“他们都没遇到过。有一个人说，他朋友在另一个评则组遇到过。但这个评则组里一个都没有。”</span>

<span style="color:#54a1f9">“这……太奇怪了。”</span>

<span style="color:#54a1f9">“也许是巧合，不过……”</span>

<span style="color:#23ba7d">“怎么了？”</span>

<span style="color:#54a1f9">“你的评则组是管社交媒体开放度与互操作性的，对吧？”</span>

<span style="color:#23ba7d">“对。”</span>

<span style="color:#54a1f9">“德尔瓦特据说是银聊的人。可这恰恰是银聊最该在意的一个议题，结果……在这个评则组里一点门路都没打进？”</span>

<span style="color:#54a1f9">“还是那句话，这也可能是巧合，不过……”</span>

她站起身。

<span style="color:#23ba7d">“等等，出什么事了？”</span>

她知道莫夫会希望她离开，好私下跟他碰一下情况。但莱克托比信任了她，她觉得同样信任他才是公平的。

<span style="color:#54a1f9">“银聊的人为什么会在意维里迪亚的学校有没有把公民课教好？银聊的人为什么那么反战？银聊的人怎么可能那么擅长把一个又一个掌则人找出来？还有……一个银聊的人身处那个位置，为什么会在银聊最在意的这条评则上完全不使劲——明明只要在开放度和互操作性上做出成绩，就能拿到可观的回报？”</span>

<span style="color:#54a1f9">“德尔瓦特不是银聊的人。”</span>
