# 第三十一章

<p class="dateline">北林，维里迪亚 · 3725年雨月2日</p>

泽、白和穆沿着山侧的阶梯慢慢往上走。山的两面都覆着厚雪，阳光从雪面反射过来，刺得他们睁不开眼。雪面之上只看得见松树和带扶手的阶梯——树和扶手露在外面，是因为它们太高，雪盖不住；阶梯本身露着，则是因为有架无人机在定期清雪、撒盐——他们看得见，那无人机就在上方约30米处。

一股强劲的冷风扑面而来。他们继续往上爬。几分钟后，他们登上了山顶的圆形平台。

从那里望去，北林所在的那座岛一览无余。岛宽约20公里——小到这一带最简略、缩放到最小的地图干脆懒得画它，却又大到让人觉得，真到了万不得已的时候，光凭这座岛就足以养活一个文明。泽心想，北林若是一座泽国城市，早该有一套完全自给的应急产业了。

东边是北林的主城区。西面和北面，积雪的丘陵连绵数公里，一条小径缓缓蜿蜒，向森林深处下行。泽往东俯视，看见另一条通上山顶的阶梯，一个年轻人只穿着一件毛衣、戴着一顶轻便兜帽，正往上爬。

等那人快到山顶时，泽认出了一张熟悉的脸。

<span style="color:#df74b1">“德鲁因！”</span>他喊道。

德鲁因抬起头，看见泽，三步并作两步跑完最后20米台阶。

他登上山顶，一把抱住泽，差点把他撞得站不稳。

<span style="color:#e58137">“泽，你还活着，我太高兴了，终于又能见到你了。”</span>

德鲁因慢慢松开泽，转向白。

<span style="color:#e58137">“等等，我是不是在哪儿见过你？”</span>

<span style="color:#ed756b">“我是白。萨祖都的练习赛，你可能见过我在旁边看。”</span>

<span style="color:#e58137">“啊，对，我记得你！”</span>德鲁因答道，心里却有点拿不准：自己是真的记得见过她，还是只是在凭空编造一段记忆。

<span style="color:#00bc96">“我是穆。你可别把我和苏搞混了——她还在泽国，跟我完全是两个人。”</span>

<span style="color:#e58137">“你好啊，穆。”</span>德鲁因笑了笑。

<span style="color:#df74b1">“那就说吧。到底发生了什么？”</span>

<span style="color:#e58137">“这事说来话长。你确定要在这么一座冷飕飕的雪山顶上听？”</span>

泽、白和穆立刻一齐点头。

<span style="color:#e58137">“看来你们比我预想的更适合在红郡生活！”</span>

<span style="color:#e58137">“好吧，那我开始讲。”</span>

<span style="color:#e58137">“那还是葡期的事。他们占领红郡大概两个月后，几个北极军官上门来找我父母谈话。我父母从来不太把北极的威胁当回事，总说我们该对和平更开放一些，多跟他们合作。可入侵一开始，他们一下就变成了北极所作所为的坚定拥护者。红郡有相当大一部分人也是这样。”</span>

<span style="color:#e58137">“北极人给了我父母一个职位，想请他们去琉璃冠，给最高领导层当整合顾问——先是整合被占领的红郡人口，然后是北林居民，最后是所有他们将要征服的人。”</span>

<span style="color:#e58137">“我做了一个风险很大的决定。我决定‘归化’过去——装作完全拥护北极事业的人，利用我父母的声望，加上我自己那个民本棋冠军的头衔——”</span>

<span style="color:#df74b1">“民本棋冠军是我！”</span>泽打趣地插了一句。

<span style="color:#e58137">“那是因为比赛取消了，他们直接把头衔给了你。你从来没赢过我。”</span>

<span style="color:#df74b1">“两天前那场战斗，我赢了你！”</span>

<span style="color:#e58137">“那首古诗里那句是怎么说的？mi fu zo de tei ka ciu pin——当我战败时，却觉得自己赢了？”</span>

<span style="color:#df74b1">“你总算开窍了！”</span>

<span style="color:#e58137">“总之，我靠父母的声望，加上我身为民本棋半决赛胜出者的身份，一路往上爬。两个月内，他们就独立摸索出，民本棋是训练现代战争人才的有效方式——”</span>

<span style="color:#df74b1">“等等，他们真弄明白了民本棋是干什么用的？”</span>

<span style="color:#e58137">“等等……你是说，你们有意把民本棋锦标赛设计成培养防卫人才的？”</span>

泽、白和穆立刻点头。

<span style="color:#e58137">“那倒没有。他们绝对没弄明白。他们只是发现，民本棋**恰好**对这个用途有效。于是3个月内，他们就把我提成了最高指挥官之一。”</span>

<span style="color:#e58137">“其实北极人挺好摆布的，你知道吧。”</span>

<span style="color:#df74b1">“怎么说？”</span>

<span style="color:#e58137">“他们那一整套意识形态完全不看重对齐，只看重能力。在他们眼里，顶尖人才是可以互换的。人不过是机器人，薪水开高一点就能被重新分配。他们压根没有‘人各有各的动机、各做各的10万个梦’这回事，也分不清谁的心是跟你一起跳的，谁只是在装。所以你只要喊对口号，让他们相信你是顶尖人才，他们就会……信任你。”</span>

<span style="color:#df74b1">“哇。”</span>

<span style="color:#ed756b">“我……倒不觉得意外。”</span>白补了一句。<span style="color:#ed756b">“我只是庆幸，这盘棋你下得比谁都好。”</span>

<span style="color:#00bc96">“那北极帝国最有意思的地方是什么？”</span>穆轻声问。<span style="color:#00bc96">“我们能从他们身上学到什么？”</span>

<span style="color:#e58137">“他们的技术进步是真的，而且很惊人。他们给北林居民做的那些治疗只是一个样本。他们相信自己已经弄明白了怎么让人多活10年，而且还在加速。”</span>

<span style="color:#e58137">“琉璃冠是我见过最迷人的城市之一，它的美很独特。走在城里，就像住在一颗巨大的冰晶里。最高的塔离地一公里，地下洞窟深不见底。”</span>

<span style="color:#e58137">“有些墙边甚至种着一排排松树。这本身就是一项了不起的工程：用基因工程让植物更耐寒，再加上地下供暖和巧妙设计的反射墙，把周围环境弄得更暖。”</span>

<span style="color:#e58137">“冬天，琉璃冠有一个半月的极夜，见不到太阳。那时整座城市就被白与蓝的人造光裹住。”</span>

<span style="color:#df74b1">“听你这口气，像是想回去了！”</span>

<span style="color:#e58137">“其实我想要的是别的。北极人把这些技术造出来，我觉得是好事——真要让我关掉一样，那就是超级病毒的研究。但危险的地方在于，他们造出来的一切都自己留着，不让别人受益。就连给北林人一点，也得按他们的规矩来——你来我们的诊所，你没资格知道我们在你身上做了什么；你要是不想变回原来的样子，就得一次又一次地回我们诊所来。”</span>

<span style="color:#e58137">“科学技术本该把世界连在一起，结果却让一个群体变成越来越大的威胁，让世界其余部分越来越害怕。”</span>

<span style="color:#e58137">“但多亏了你们，我们——我们指的是全人类——现在缴获了他们一大堆技术。有些是他们带进北林的；成堆的军用装备散落在埃莱纳森林各处；还有一批在塔尔杜尔岛上，那是北极的核心领土，上面住着几万人。”</span>

<span style="color:#e58137">“所以我们下一步该做的，是尽可能说服他们中的更多人自愿站出来，自愿分享知识和专长，把整个世界至少拉到北极人自己独享的那条技术前沿上。”</span>

<span style="color:#df74b1">“开源——不只是一个好主意，这是铁律。”</span>泽答道。

<span style="color:#e58137">“正是。让整个世界在这方面更像维里迪亚一点。”</span>

<span style="color:#df74b1">“然后我们可以把他们的策略反过来用。让塔尔杜尔的人看到，在我们的生活方式下，他们能有更多安宁、更多和平、更多真正的自由，同时还能拥有强大的技术。也许通过他们，我们能说服更多北极人站到我们这边来。”</span>

谈话停了下来。这回德鲁因绕着山顶走了一圈，欣赏北林的景色。

大约10分钟后，穆又开口了。

<span style="color:#00bc96">“德鲁因，我有个坏消息。”</span>

<span style="color:#e58137">“什么消息？”</span>

<span style="color:#00bc96">“自由城防卫队报告说，红郡的北极驻军已经增加到3倍。他们用我们两天前那场战斗里发现的招数，拿早就在红郡的那些无人机试了几次破坏行动，但现在大多都失败了。”</span>

<span style="color:#00bc96">“他们现在认为，我们基本没有可能夺回红郡了。”</span>

德鲁因叹了口气。他眼里满是深重的悲伤。

<span style="color:#00bc96">“塔芬德尔建议我们来点硬的。封死塔尔杜尔与北极其余领土之间的边界，然后提出一笔交易：想回北极帝国的人，我们放他们回去；作为交换，红郡想离开的人，也允许他们离开。他们留着红郡，我们留着塔尔杜尔。然后在维里迪亚找一个美丽的地方，建一个新的红郡。”</span>

<span style="color:#df74b1">“干脆把这里和塔尔杜尔之间那个半岛给他们不好吗？就是从北岸东端垂出去的那个。那边土地很美。”</span>

<span style="color:#00bc96">“我觉得那该由他们自己决定。”</span>

德鲁因点了点头。<span style="color:#e58137">“塔芬德尔大概是对的。这已经是我们能拿到的最好结果了。”</span>

谈话又一次停下。4个人一起望向东方，看雪花轻轻落在北林镇的每一栋建筑上，渐渐积起厚厚一层。

---

格拉迪亚斯和塞拉穿过北林大梅港入口处那道巨大的石门。闸机已被砸烂、掀倒在地，好让人们自由进出，管理人员那时候似乎也狠不下心去执行什么签证规定。两名大梅港保安穿着紫灰两色的制服，只是看着人流进出，也只能退而求其次：保证不出偷盗和暴力事件。

塞拉的手表震了一下。她抬起手看了看。

她点了进去，看了看那些照片。前3张是自由城的人们在街头和公园里庆祝。

第四张像是在停车场里办的一场露天公开演唱会。背景里是一座巨大的厂房，侧面醒目地挂着伊查拉的标志——这是自由城如今有名的防务公司之一。

最后一张是扬本人的自拍，跟他合影的像是那家防务公司的一位经理。

<span style="color:#be9b00">“你要去自由城看扬吗？”</span>

<span style="color:#54a1f9">“其实我在想，你走之后我在这儿再待个五天左右，让他过来。他一直想来看看维里迪亚。”</span>

<span style="color:#be9b00">“应该这样。”</span>格拉迪亚斯温和地说。

他们沿街往前走了约100米，然后下到一条隧道里。又走了约200米，他们右转，登上一段阶梯。阶梯尽头有一扇门。

格拉迪亚斯准备拿手表去碰门边的绿色圆圈，可还没碰上，门自己开了。

<span style="color:#23ba7d">“爸爸！”</span>莉莉喊着跑向格拉迪亚斯，抱住了他。

<span style="color:#be9b00">“莉莉！你没事，我太高兴了。”</span>

费布里克和赫雷达从另一个房间出来，冲上前抱住格拉迪亚斯和塞拉。

<span style="color:#54a1f9">“你们能聚在一起，我太高兴了。”</span>

<span style="color:#23ba7d">“对不起，妈妈。”</span>

<span style="color:#54a1f9">“别道歉。过去这一年，我们每个人都犯了很多错。现在我们都熬过来了；真需要的话，再难也能熬过去。我们是一家人。”</span>

<span style="color:#23ba7d">“兹文在吗？”</span>

<span style="color:#54a1f9">“哦，兹文、维尔和黛雅明天早上到！”</span>

<span style="color:#aaa300">“太好了！我特别想见到妈妈！”</span>赫雷达叫道。

<span style="color:#be9b00">“大梅港待你们怎么样？”</span>格拉迪亚斯问。

<span style="color:#aaa300">“其实还挺好玩的。”</span>赫雷达答道。<span style="color:#aaa300">“他们组织教育、娱乐、公共活动都很有一套，想尽办法让人开心。他们还说动了北极人，允许无人机运食物进来，所以除了地方小、封得严实，其他都还好。”</span>

<span style="color:#ce9200">“我们在这儿出于好奇吃过几次北极食物。”</span>费布里克接话。<span style="color:#ce9200">“他们弄出了十来种物质，尝起来像糖，却一点热量都没有。还有些蛋白制品，味道像鱼和肉。还不错！他们的口号是：想要什么口味都行，营养配比也随你需要。”</span>

塞拉默默低下头。她还是不太习惯承认：北极人的做法有时确实有可取之处，也能从中学到东西。

<span style="color:#be9b00">“要不我请几位新朋友过来，”</span>格拉迪亚斯插话道，<span style="color:#be9b00">“让他们给我们露一手，尝尝正经做出来的泽国菜该是什么味道？”</span>

<span style="color:#23ba7d">“好耶！”</span>莉莉喊道。

费布里克和赫雷达也迫不及待地点头。

<span style="color:#be9b00">“那我就请他们今晚来。今天下午我还得再出去一趟。山顶上要为登和阵亡的将士举行一场军葬。之后我们一起下来，好好吃一顿。”</span>

莉莉、费布里克和赫雷达兴奋地点头。
