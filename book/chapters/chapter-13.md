# 第十三章

<p class="dateline">梅尔丹，维里迪亚 · 3724年获月8日</p>

格拉迪亚斯掀开布帘，走进隔间。这种隔间的陈设他如今已经再熟悉不过：一张桌子，尽头是一盏装饰灯和两枝花，地板上有一台空气过滤器紧贴着墙角。

德尔瓦特已经坐在里面了。

<span style="color:#e58137">“掌则人会议开得怎么样？”</span>德尔瓦特问。

<span style="color:#be9b00">“挺有意思。”</span>格拉迪亚斯答道。

<span style="color:#be9b00">“说实话我还挺意外。‘我们不该事事都插手那么多，评则该少一些’——提这话的远不止我一个。感觉差不多一半的一年级掌则人都抱着同样的想法，而且提得跟你希望我做到的一样主动。”</span>

<span style="color:#e58137">“所以至少有些人，不希望你歌里冒一句脏话就被征税，也不希望你每盖一栋房子、一套公寓，都要在五种不同的无障碍要求上被管得死死的？”</span>

<span style="color:#be9b00">“我是说，我不觉得现在有那么糟。我们没像英格尔沃那样，什么事都让人填表。税不过是人们要盯着的又一个变量，跟电费一样。可即便这样，我想掌则人也明白，我们得讲道理，不能管得太细。”</span>

<span style="color:#e58137">“他们讲得站得住脚吗？”</span>

<span style="color:#be9b00">“常常比我讲得还好。二年级和三年级的掌则人更爱怀疑，观念也更传统。一碰到跟泽国或者北极威胁有关的事，这一点就尤其明显。”</span>

德尔瓦特叹了口气。<span style="color:#e58137">“这些东西上宣传了几十年。说句实话，北极人自己也没把形象做好；他们干的每一件事——在红郡附近巡逻的无人机，甚至埃菲里昂的演讲——总是把人惹得火大。”</span>

<span style="color:#be9b00">“是啊，一堆人觉得他们要对红郡搞一场更严重的破坏行动。”</span>

<span style="color:#e58137">“你觉得他们会搞出一场更严重的破坏行动吗？”</span>

格拉迪亚斯想了想。他心里其实没底；他预计短期内不会出事，却又怕答案是个“会”。可他也知道，一旦向德尔瓦特承认这一点，对方就会长篇大论地教育他，说他那些消息来源有多偏——而这还没算上他*从没*跟德尔瓦特提过塞拉在自由城见过泽、白的事。

<span style="color:#be9b00">“大概不会。”</span>

<span style="color:#e58137">“那你就尽力去说服他们，别让他们担心。”</span>

一个机器人进来，给格拉迪亚斯端来一杯水和一份沙拉，给德尔瓦特端来一杯茶，外加一根长方形的营养棒。

两人安静地喝，然后吃。

他们又聊了一小会儿，大约二十分钟后，格拉迪亚斯站了起来。

<span style="color:#be9b00">“抱歉，我得走了，约好了回家陪家人吃饭。”</span>

<span style="color:#e58137">“那当然得去，家人才是最重要的！”</span>

格拉迪亚斯走出隔间，沿着大梅港的通道往出口去。

---

在通道里走了大约十分钟，格拉迪亚斯钻出地面，上了一条步道。大梅港高大的入口门就在正前方。他穿过闸机，重新回到梅尔丹商业区那片绿意、玻璃与钢铁交织的景象里。

格拉迪亚斯向右拐，动身往家走。

他的手表震了一下。

格拉迪亚斯对着颈带低声说话，给莫夫拨了通电话。

<span style="color:#be9b00">“怎么了？”</span>

<span style="color:#00bc96">“他这次比平时大意了些。”</span>莫夫说。<span style="color:#00bc96">“我跟到了他下一场会面。对方是另一个掌则人。我占了隔壁的隔间，靠墙上的震动就能听见。”</span>

<span style="color:#be9b00">“哇。大梅港的隔间比掌则人用的那种差这么多？”</span>

<span style="color:#00bc96">“嗯。我觉得知道这差别的人还不够多。”</span>

<span style="color:#be9b00">“而我们用那种隔间聊了好几个月……”</span>

<span style="color:#00bc96">“确实……好吧，现在知道了。”</span>

<span style="color:#00bc96">“总之，那个掌则人也在硬件开放度评则里，只是跟你不属于同一个讨论组。他完全赞同德尔瓦特的那套主张。”</span>

<span style="color:#be9b00">“然后呢？”</span>

<span style="color:#00bc96">“整场谈话都在盘算，怎么说服那一组里的其他掌则人跟着他的立场走。”</span>

<span style="color:#00bc96">“德尔瓦特非常强势。他好像真的很在意这件事。而且，有你，再加上那个掌则人，他在同一条评则的两个讨论组里都安插了联系人。分组讨论本来的用意，就是逼人独立思考——可不是让所有人都听同一个人的指挥！”</span>

<span style="color:#00bc96">“总之，我确信这件事比我们所有人想的都更有组织、也更深。”</span>

<span style="color:#00bc96">“下次你跟德尔瓦特谈，我觉得你该要他给个说法。”</span>

<span style="color:#be9b00">“你觉得那会是什么？某种有组织的政治行动，想把维里迪亚变得像自由城，却不要自由城对抗北极的那一部分？所以不是一个人信这套，他背后可能有一整张网？”</span>

<span style="color:#00bc96">“我也很好奇。”</span>

格拉迪亚斯上了巴士。

他叹了口气。

<span style="color:#be9b00">“我再想想。我这就回家，跟家人吃顿饭。孩子们今天回家了。”</span>

<span style="color:#00bc96">“嗯，好好想。还有——多保重。”</span>

---

格拉迪亚斯下了巴士，朝餐厅走去。他穿着隐私袍，走得很快，在烈日下出了一身汗。

几分钟后，他到了。塞拉和四个孩子已经坐在桌边。

<span style="color:#54a1f9">“惊喜！”</span>塞拉喊道。<span style="color:#54a1f9">“这回我们比你先到。”</span>

格拉迪亚斯的脸上绽出笑容。他很高兴又见到孩子们。上次去他们家小住的那一晚，已经是两个月前；而孩子们离开他和塞拉的家，也已有半年。

格拉迪亚斯把关于德尔瓦特和莫夫的念头收起来，刻意把注意力放到家人身上。

几分钟后，一个机器人滑到桌边，端来费布里克和赫雷达的饭菜。

<span style="color:#54a1f9">“你的数学考试考得怎么样？”</span>塞拉问赫雷达。

<span style="color:#aaa300">“96分。”</span>赫雷达答道。

塞拉脸上的神情立刻变成了担忧。她知道，这下更不好开口问莉莉了。她本来打算紧跟着就问她，可这会儿只是转而祝贺了赫雷达一句。

莉莉的眼睛垂了下去，盯着自己面前的桌面。

机器人又滑到桌边，端来兹文和莉莉的饭菜。兹文急急地接过，莉莉没动。

格拉迪亚斯把莉莉那份拿过来，放在她面前的桌上。

莉莉慢慢开始吃，什么也没说。

桌上安静下来。他们慢慢吃着，一边看旁边屏幕上正播着的职业翔球赛。

突然，翔球比赛中断了，换成一段完全不同的节目。

屏幕左侧出现埃菲里昂勋爵的影像，右侧是一篇分了好几段的消息。

格拉迪亚斯飞快地扫了一遍消息，环顾四周。塞拉已经从桌边站起来，正想法子把屏幕的电源拔掉，甚至不等餐厅店员赶到。

费布里克和赫雷达继续吃。兹文好奇地盯着屏幕上的消息，脑子在几段话之间跳来跳去，偶尔又把注意力转去看塞拉怎么关屏幕。莉莉则只是盯着那篇消息。

屏幕终于关掉了。

一家人沉默下来。费布里克掏出手持终端，开始复习功课。莉莉也掏出手持终端，手指飞快地敲着。格拉迪亚斯看不见她在做什么，不过她像是在玩某种游戏。

一家人静静地吃。五分钟后，莉莉的脸忽然亮起来，悄悄欢呼了一声。她放下手持终端，也跟着吃起来。尽管她开始得比谁都晚，却比所有人都先吃完。

<p class="scene-break">3724年获月9日</p>

格拉迪亚斯拉开隔板，走进隔间。其他掌则人都已经到了。

<span style="color:#7499fb">“又见到你了，六号！”</span>十三号喊道。

<span style="color:#be9b00">“等等，你怎么知道我是六号？”</span>

<span style="color:#7499fb">“凭直觉。大概是你的肢体语言里某个细微之处——都说，我们九成的交流都是下意识的。”</span>

<span style="color:#be9b00">“哈，看来就算遮住脸、隔着颈带说话、再用 AI 重新随机生成的声音把话放出去，我还是分不出你们谁是男谁是女。这些物理上的隐私手段，终究还是有极限。好吧，也高兴见到你，十八号。”</span>

<span style="color:#7499fb">“我是十三号！”</span>十三号答道。<span style="color:#7499fb">“看来对你来说，交流大概只有三成是下意识的。”</span>

<span style="color:#7499fb">“顺便说，我是女的。我觉得这话可以说，毕竟只把我的匿名集缩小了一半。”</span>

<span style="color:#7499fb">“总之，再过大约两个月，我们就得就这条评则投票了——这是我们投票前最后一次碰面。”</span>

<span style="color:#be9b00">“我们有提案了吗？”</span>

零号抬起头。

<span style="color:#df74b1">“我起草了修改后的条文。”</span>他插话道。<span style="color:#df74b1">“把一切军事、监视和反监视产品排除在开放度税评则较优惠的档位之外。这些东西一律无条件地从第3档起算。”</span>

<span style="color:#be9b00">“反监视也算？”</span>

<span style="color:#df74b1">“当然。都是同一场零和博弈的一部分。”</span>

十八号开口了。

<span style="color:#db8916">“我还是觉得，你们根本不懂北极的威胁。他们有技术优势。这不是一场对称的博弈。如果这些领域里人人都得自己做技术，赢的是北极人。”</span>

<span style="color:#00bbad">“得了吧！他们不会动手的。自从无人机发明出来，这么多年他们一直让无人机在各地嗡嗡转。他们才不会真在红郡闹出什么疯狂的事，好吧？”</span>

<span style="color:#db8916">“你真这么想？”</span>

格拉迪亚斯环视房间。他读肢体语言的本事确实不怎么样。但据他判断，另外几个人里有三个倾向于把军事、监视和反监视从硬件开放度评则里砍掉，十三号立场居中，只有十八号和一号反对。

前一天和莫夫的谈话让他变得多疑。以前他心态更开放。现在他开始想，今年对这条评则什么都不动，也许才是上策。他的脑子转来转去，想找出把局面往更有利的方向推的办法。想了大约半分钟，他有了主意。

<span style="color:#be9b00">“我刚想到一个办法。”</span>

其他人都转向格拉迪亚斯。

<span style="color:#be9b00">“我们不必现在就定下来。离投票还有两个月，对吧？”</span>

<span style="color:#7499fb">“没错。”</span>

<span style="color:#be9b00">“十八号，你觉得北极帝国多久会动手，对红郡搞出更严重的破坏？”</span>

<span style="color:#db8916">“肯定不到两个月。”</span>

<span style="color:#be9b00">“一号，我记得你也主张该认真把北极人当作威胁来看待。你估的是多久？”</span>

<span style="color:#00b9c3">“十天到二十天，也许一个月。不会是太剧烈的事，但总会有某种破坏。多半会被报成一起大事故——向来都是这么收场的。”</span>

<span style="color:#be9b00">“那这样如何？当然，这没有约束力，只是个初步想法。我们不妨都等上两个月，看看会出什么事。如果没有袭击，那我们就都会更愿意接受零号的修正案。但如果有，我们就把这条评则原样保留，甚至把各税档之间的差距再拉开。”</span>

零号小声嘟囔了两句，算是表达不满，但没把话挑明。他显然不喜欢被人这样逼着表态。可他找不出任何理由反驳格拉迪亚斯的提议。

十八号的反应也差不多。和零号一样，他不喜欢被逼着表态，却不得不承认，自己也想不出更好的办法来打破僵局。

<span style="color:#be9b00">“那就这样吧。”</span>
