# 第十章

<p class="dateline">自由城，联合城邦 · 3724年风月24日</p>

扬的出租车停在自由城经济研究所门口，他在这里做研究员。他下了车，走进大楼，用手持终端碰了一下闸机付费进楼。

他余光瞥见，入场费比之前高了10%。

他走向餐厅区，看见大多数桌子都满了。只有一张桌子还有空位，而且已经有个女人坐在那儿。

<span style="color:#78b249">“这儿能坐吗？”</span>扬问。

<span style="color:#8d92f9">“当然。”</span>

扬坐了下来。

<span style="color:#78b249">“我叫扬。”</span>他主动说。

<span style="color:#8d92f9">“我叫乌塔库。我来自贝尔帕基，在研究所读博士。”</span>

一个机器人滑到扬身边，递上菜单。

扬很快扫了一遍，点了一份蔬菜配鱼，还有一杯水。

他发现这里的价格也比以前高了。

<span style="color:#78b249">“哇，现在什么都涨价了。”</span>

<span style="color:#8d92f9">“你没看新闻？”</span>

<span style="color:#78b249">“从哈普顿开完会回来就没看。”</span>

<span style="color:#8d92f9">“嗯，可这消息在哈普顿也该传开了。到处都在说要提高国防预算。”</span>

<span style="color:#78b249">“北极恐慌？”</span>

<span style="color:#8d92f9">“对，他们的无人机活动越来越频繁。可奇怪的是，不少政客对此完全无动于衷。真正当回事的，好像只有红郡和它周边几个城邦。”</span>

<span style="color:#8d92f9">“嗯，还有自由城，不知怎么就也算上了。”</span>

<span style="color:#78b249">“为什么是我们？我们这么上心，我倒挺高兴，可联合城邦里差不多有一半离红郡比我们近，他们才该更担心！”</span>

<span style="color:#8d92f9">“嗯，德文维尔是当真的——毕竟德文维尔议会有12%的席位是红郡选的。可德普莱西、翁达克、因伯，一点都不上心。”</span>

<span style="color:#8d92f9">“是挺怪的。别忘了，按宪法，这里的政府只能收基础土地税，再加上从自有自然资源资产上收的一点租金，不能多收。所以认真对待这个问题的根本不是政府，而是那些巨型企业。”</span>

机器人回来了，端着扬的饭菜和水。扬接过那盘食物放到桌上，又拿起水杯，立刻喝了一口。

<span style="color:#8d92f9">“他们现在把营收的3%捐给国防，甚至还串通起来惩罚不捐的公司。莫格纳本来不愿意出钱——他们说了些腐败之类的话，不过大家都觉得他们只是抠门——结果那些充电站厂商联合起来，威胁说除非莫格纳也加入，否则就把莫格纳的车挡在他们的充电网之外，那可是自由城90%的充电站。昨天莫格纳认了。”</span>

<span style="color:#78b249">“这……够狠。要是放在平时，哪个行业敢这么干，自由城得有一半人反过来串通对付他们，说不定还会出钱扶5家新公司跟他们打对台。”</span>

<span style="color:#8d92f9">“平时是这样。可你也知道，现在时势不同了。”</span>

---

<p class="scene-break">梅尔丹，维里迪亚</p>

<span style="color:#54a1f9">“要去参加你的第一次掌则人会议了？”</span>塞拉问格拉迪亚斯。

<span style="color:#be9b00">“我的头两场掌则人会议，连着开。第一场是活动与演出中的文化价值评则——其实就是当年我给恐结打分的那条评则。”</span>

<span style="color:#54a1f9">“哦，那场活动与演出中的文化价值评则，要讨论什么？”</span>

<span style="color:#be9b00">“我在群里说过，我觉得这条评则是在把大家往一味平淡上引，只求不冒犯任何人。没想到还有几个人赞成。这次我想使劲推一把，把这点改掉。”</span>

<span style="color:#54a1f9">“Veridia ba ‘fun’ gie！”</span>塞拉开玩笑道。

<span style="color:#be9b00">“该换掉的不是那个‘gie’吗？‘fau’只是‘再’的意思。”</span>

<span style="color:#54a1f9">“啊，对。”</span>

<span style="color:#be9b00">“不过没错。维里迪亚会重新有意思起来。”</span>

<span style="color:#54a1f9">“那第二场呢？”</span>

<span style="color:#be9b00">“硬件开放度评则。议题是要不要修改它，把军用和监控产品豁免出去。”</span>

<span style="color:#54a1f9">“嗯？那有什么利弊？”</span>

格拉迪亚斯仔细斟酌着该怎么说。他犹豫了一下要不要提德尔瓦特，最后还是决定不提。

<span style="color:#be9b00">“这个嘛，”</span>他开口道，<span style="color:#be9b00">“有些掌则人认为我们该从资助战争里抽身——那是负和博弈，双方都有更好的炸弹和战斗无人机，结果还是一样，只是炸掉的东西更多、受伤的人更多。”</span>

他对自己这番话很满意。他隐隐觉得，塞拉对任何可能伤到泽国的事都很敏感，会求他采取对泽国最有利的立场。他绷紧了神经，等着塞拉的下一个问题。

<span style="color:#54a1f9">“可是资助……那不是更多属于图谱资助那边的问题吗？”</span>

格拉迪亚斯在心里松了口气。

<span style="color:#be9b00">“别忘了，我们也造武器，还有监控产品。而评则会左右我们把多少看家本领留给自己。”</span>

<span style="color:#54a1f9">“原来是这样……”</span>

<span style="color:#54a1f9">“那好吧，开完会记得告诉我怎么样！”</span>

---

格拉迪亚斯沿走廊走下去，进了一处庭院。那里排着一列隔间，装着厚实的滑动门。他照吩咐走到最右边那间。

他把隔板拉开。这要费不小的力气。他立刻看出，这间隔间比大梅港那些蒙布的隔间正规得多。隔板拉开的过程中，他能看清它的内部结构：里层是一层隔信箔，接着是若干层隔音材料，还有几层他认不出来。

这时他还注意到，隔间外侧四面都持续发出低沉的嗡鸣。他明白过来：这是白噪声，用来进一步掩盖穿过隔音墙的一切声音。如果噪声是40分贝，而墙足够好，能把声音衰减50分贝，那它就能盖住里面高达90分贝的声音——想留安全余量的话，也许70分贝。这足以完全盖住任何交谈。

隔板完全拉开后，格拉迪亚斯朝隔间里看去。一张桌子从门口附近一直伸到对面的墙，两侧各有一条长凳。

里面已经坐了5个人，都穿着隐私袍。

<span style="color:#7499fb">“欢迎！你一定就是四号。”</span>其中一人大声说道。

<span style="color:#be9b00">“正是。”</span>

<span style="color:#7499fb">“在这个掌则人小组里我是二十号，三年级。我们有两个二年级——不过十一号还没到——两个三年级，另外两个一年级，现在再加上你。”</span>

<span style="color:#be9b00">“很高兴认识各位。”</span>

格拉迪亚斯在二十号旁边的长凳上坐下。二十号的手持终端开着，格拉迪亚斯能看到他在翻最近的审计——那些审计评估各家企业在文化价值评则上的状况，以及由此作出的裁定。

过了一会儿，又一个掌则人走了进来。他回身把隔板拉上，坐了下来。

<span style="color:#54a1f9">“那么，文化价值评则。”</span>另一个三年级开口道。

<span style="color:#00b9c3">“是活动与演出中的文化价值评则，”</span>那个一年级——一号——纠正道。<span style="color:#00b9c3">“我们不碰社交媒体和其他线上内容，那是另一条评则。我们也不碰建筑和公共广告牌，那些归美学税管。”</span>

<span style="color:#54a1f9">“大家都知道，在这儿不用显摆。”</span>那个三年级回了一句，语气里带着玩笑的分寸，既想点明又不愿得罪一号。

<span style="color:#54a1f9">“我们想怎么进行？也许该先就我们要解决的问题达成共识？”</span>

<span style="color:#db8916">“先过几个例子吧。”</span>一个此前没开口的二年级说。

格拉迪亚斯看到了插话的机会。

<span style="color:#be9b00">“你们怎么看恐结？”</span>

<span style="color:#db8916">“什么意思？”</span>

<span style="color:#be9b00">“上次审计，他们的税被提到了第4档。”</span>

格拉迪亚斯开始念评则。

<span style="color:#be9b00">“内容较弱地提倡以下一项或更多：暴力、违法行为、使用不推荐物质、赌博或高风险投资、过度炫富、糟糕的冲突处理方式、宗教或族群仇恨。”</span>

<span style="color:#be9b00">“我们觉得恐结犯了提倡暴力、违法行为或仇恨这一条吗？”</span>

<span style="color:#db8916">“他们上一首歌写的就是毁城、剥人皮。凭什么不算？”</span>

<span style="color:#be9b00">“我们真觉得那些词会让人想在现实里剥谁的皮吗？那只是一首歌。我记得几年前游戏也闹过这一出，最后科学界给出的结论是：游戏可能略微增加几种攻击性行为，但没有证据表明它们真的会导致暴力。”</span>

<span style="color:#db8916">“我也记得。不过我的理解是，证据给出的结论比这更严厉。”</span>

<span style="color:#54a1f9">“要不要把那些研究翻出来，一起过一遍？”</span>

另外几个掌则人点了点头。他们开始对着手持终端低声下指令。

格拉迪亚斯趁势接着往下说。

<span style="color:#be9b00">“可就算抛开这些不谈，我们真想让维里迪亚变成这样一个社会吗——创作者时时刻刻得操心这个，歌、游戏、电影全都变得无聊苍白？”</span>

<span style="color:#00b9c3">“他们不必时时刻刻操心。这正是维里迪亚这套监管体系的意义。我们不是禁掉他们，只是把他们的税调高一点，而不是调低一点。他们本来就有10件事要操着中等程度的心——粉丝喜欢什么、什么会得罪或不会得罪赞助企业，等等——这些事不会压垮他们，但确实有影响。我们只是请他们多想一件事：公共利益。”</span>

格拉迪亚斯决定换个角度再试。

<span style="color:#be9b00">“其实总的来说，我挺喜欢这条评则。北林科学中心让孩子们能在那儿了解化学、生物和火箭，是那么好的一个地方，因此得到奖励，我觉得很好。”</span>

<span style="color:#be9b00">“可暴力是生活的一部分。人类最初不过是一群为香蕉打架的猴子。我们还住在森林和洞穴里的时候，我们的男人每4个就有一个死于他人之手。学校里逼我们研读背诵的史诗里有暴力。每一部《大典》里的英雄都干过暴力的事。我不认为我们该让维里迪亚人完全回避人性中如此核心的一部分。如果我们让公共媒体永远处处避开暴力，那人们关于暴力的所有观念就只能来自互联网的阴暗角落——那些地方可收不到税——那只会更糟。”</span>

<span style="color:#7499fb">“有研究试着量化过这个吗？”</span>二十号插了一句。

<span style="color:#be9b00">“我不知道这件事能不能用研究量化。”</span>格拉迪亚斯回答。

另一个三年级又开口了。

<span style="color:#54a1f9">“这样很好。我感觉我们已经提出了几个重要问题，不只是科学层面的，还有我们底层的目标和价值。”</span>

<span style="color:#54a1f9">“我觉得该把当年那些游戏研究重读一遍。另外，也该看看维里迪亚民众怎么看这件事。能让翡翠做一份广泛聆听报告吗？听听过去一年人们在蓝鲸或银聊上是怎么说恐结的。”</span>

<span style="color:#db8916">“我不觉得社交媒体上的言论，就一定是判断什么对人有益的可靠依据。”</span>十一号插话道。

<span style="color:#54a1f9">“好，不过我们现在就花点时间读一读吧。”</span>

格拉迪亚斯点头。另外几个掌则人也跟着点头。

<span style="color:#54a1f9">“稍等一分钟。蓝鲸从来都只让人用他们自己的界面看站内消息，我有几个绕过去的办法。”</span>

差不多正好1分钟后，每个掌则人的手持终端上都弹出一个新窗口，实时显示翡翠的思考过程——它正在抓取并摘记蓝鲸和银聊上人们关于暴力与恐结的言论。

掌则人们都开始紧盯着自己的手持终端——有人读电子游戏的研究，有人看翡翠思考。

---

格拉迪亚斯站在外面，小口喝着一杯温水。他的第一场掌则人会议开了75分钟，已经结束，他正在用这25分钟的休息时间。

他的手表震了一下。

该走了。

格拉迪亚斯拐过弯，走完最后几步，来到隔间前。

他很快到了，拉开隔板。

里面已经坐着两个掌则人，一边一个。两人都穿着隐私袍，兜帽和面罩都还戴着。

<span style="color:#be9b00">“两位好！”</span>

<span style="color:#db8916">“你好！我是十八号。你是几号？”</span>

<span style="color:#be9b00">“我是六号。”</span>

<span style="color:#00bbad">“我是九号。”</span>

十八号想了片刻，然后站起身。

<span style="color:#db8916">“等等，趁别人还没来，你们能不能都再站起来一下？”</span>

格拉迪亚斯和九号都站了起来，暂时走出隔间，开着门从外面往里看。

<span style="color:#db8916">“好，我们看看。”</span>

十八号把手持终端切到另一种模式，开始在屋里四处挥动。他又取出一架无人机，在手持终端上按了几个键。无人机开始贴着屋子边缘飞，桌子上面和下面都转了一圈。

十八号和九号默默看着扫描，又有两个掌则人到了，悄悄站到他们身边。

<span style="color:#db8916">“嗯，没有东西在发射信号，热成像也没探到任何通电的电子设备。”</span>

1分钟后，无人机突然在桌子远端的正中上方响了一声。

十八号拿着手持终端扑到那个位置，开始仔细查看、戳弄桌面。过了一会儿，他得意地站起来，手里举着一个针状装置，尖端有个几毫米宽的圆头。

<span style="color:#be9b00">“那是什么？”</span>格拉迪亚斯问。

<span style="color:#db8916">“窃听装置。桌面上有个小凸起，它就藏在那底下。要把这种东西插进去，事后还能把桌面补得这么好，肯定得有相当的手艺。”</span>十八号答道。

<span style="color:#be9b00">“哇。”</span>

九号走上前，看了一眼那个装置。

<span style="color:#00bbad">“我怀疑这东西不是冲着我们来的，”</span>他说。<span style="color:#00bbad">“干这种事的人，通常是想拿到企业即将公布的决策消息，再据此在金融市场上交易。目标一般是那些没那么小心的小企业。掌舵会在这上面相当安全。我们这个掌则人小组只是3个讨论组之一，就算你真偷听到，也只拿到三分之一的视角。何况我们全都通过颈带说话，声音是以数字方式在我们之间传递的。”</span>

<span style="color:#db8916">“其实这个还带了摄像头。它能读你的嘴唇和颈部动作，所以说不定还是够它辨认出一些词，尤其如果你是新手的话。”</span>

<span style="color:#00bbad">“你怎么知道？”</span>

<span style="color:#db8916">“无人机就是靠这个发现的——红外光在摄像头镜片上反射。我的手持终端也用非线性结检测器捕捉到了，可要是无人机没告诉我该往哪儿看，我很可能就漏掉了。”</span>

最后两个掌则人到了。

十八号走出去，说明了情况，大家一起看了那个窃听装置。几个掌则人用手持终端扫了它。看完之后，十八号把窃听装置掰成两半。

十八号带着大家走到几米外另一间空着的隔间，拉开隔间的门。

他花了两分钟检查新隔间里有没有窃听器，同样动用了自己的手持终端和无人机。检查完，他打了个手势，7个掌则人一起进去，在长凳上坐下。

刚到的掌则人里有一个清了清嗓子，像是准备发言。

<span style="color:#7499fb">“不如直接进入正题？”</span>那位掌则人开口道。

<span style="color:#be9b00">“好啊！”</span>格拉迪亚斯答道。

<span style="color:#7499fb">“我们要谈的是开放度评则，以及怎么为军用硬件调整它。”</span>

<span style="color:#be9b00">“嗯，材料我读过。”</span>

<span style="color:#7499fb">“另外，我跟那边的零号聊过几次。他的主张是干脆把军用硬件完全豁免。理由让他自己讲。”</span>

零号听到自己的编号，立刻抬起头。

<span style="color:#df74b1">“通常来说，开放硬件是好事，因为别人可以在上面继续做东西，大家都能受益，对吧？”</span>

<span style="color:#be9b00">“对。”</span>

<span style="color:#df74b1">“可你想想军用领域会怎样。所有人都有更好的武器，对世界其实并没有净收益。如果所有人的剑都好一倍，盾也都好一倍，两者正好抵消。”</span>

<span style="color:#df74b1">“如果所有人的剑都好一倍，盾却不变，那任何一场战争里双方的优势照样相互抵消，只是受伤的人更多。”</span>

<span style="color:#be9b00">“可如果所有人的盾都好一倍，剑不变，那不是好事吗？”</span>

<span style="color:#00bbad">“也许吧，”</span>九号插话。<span style="color:#00bbad">“可实际上比这还要复杂。万一打的是一场消耗战呢？大家都加强防御，受伤的人数不变，只是拖得更久？又或者防御增强反而削弱了威慑，于是战争更多？”</span>

格拉迪亚斯很意外：这套说法和德尔瓦特最近对他讲过的一番话像得出奇。

<span style="color:#00bbad">“说到底，博弈树太混乱了，我们根本无法可靠地确定任何事。所以我认为我们该置身事外，改为对所有军用硬件——开放的也好，不开放的也好——都提高掌舵税，推着人们去做更有用、对人类更友善、也更有意思的东西。”</span>

一个三年级插话：

<span style="color:#54a1f9">“我不认为我们什么都无法确定。看看联合城邦。它们彼此独立了几百年，还琢磨出共治这样的机制，让彼此更愿意合作，而不是干脆并成一大团——而它们能做到这些，很明显，很大程度上要归功于脚下这片大陆有那么多山脉和半岛。所以，如果大家都加强防御，就会有更多人保住自己的自由和主权。这一点我相当有信心。”</span>

十八号又举起手。其他人转向他，他开口了。

<span style="color:#db8916">“我不认为我们可以把局势当成一个黑箱来看。看看我们现在的位置：北极帝国的技术最先进，我们第二。在军事技术上，泽国和联合城邦最为落后。”</span>

<span style="color:#db8916">“所以我们公开任何与军事相关的开源成果，对北极人毫无好处，对我们则略有好处，因为我们自己造起来更容易。”</span>

<span style="color:#db8916">“但对泽国来说，那是生命线。顶尖技术上，他们没法自己搞专有研发，却很擅长照着开源方案制造和改进。20年前，我们把编程语言和形式化验证做到了这样的程度：设备代码里基本不再有能让外人从外部夺取控制权的严重错误。正因为这些东西是开放的，泽国人才得以采用这些技术，更有效地防住北极的破坏活动。”</span>

<span style="color:#df74b1">“可我们真想玩这个游戏吗，”</span>零号接着说，<span style="color:#df74b1">“对自己‘谁是好人、谁是坏人’的判断这么有信心？计算机安全是防御性的，那没问题。可我们下一项发明出来的技术可能是进攻性的。那我们岂不是只会让所有人的军备竞赛进一步加速？”</span>

<span style="color:#df74b1">“我甚至不太相信北极人有那么大的威胁。没错，他们现在在联合城邦北部晃悠的无人机更多了，但我不觉得意图是攻击。我认为他们只是想用实力震住我们，好让我们向往他们的意识形态。”</span>

<span style="color:#be9b00">“你觉得我们该更接受他们的意识形态吗？”</span>

<span style="color:#df74b1">“我觉得该保持开放的心态。只是别忘了，泽国人也肯定在试图操纵我们。”</span>

讨论安静了片刻。格拉迪亚斯没有急着开口。他还想先弄清别人是怎么想的，再形成自己的看法。

<span style="color:#7499fb">“大家先各自再想想。这事我们还会继续谈，后面还有几场讨论，最后一场在4个月后。而真正的表决要等到6个月后。”</span>

---

<p class="scene-break">帕佛盖都，泽国</p>

白和泽一起坐在院子里的一张桌旁，两人都盯着各自的手持终端。

<span style="color:#ed756b">“芬这次不来？”</span>白问。

<span style="color:#df74b1">“不来，”</span>泽答道，语气里的失望很明显。<span style="color:#df74b1">“他在忙班孙培的事。”</span>

手持终端震了一下。轮到他们的干预回合了。泽摆下几架滑翔机和几艘载符飞船。几百个回合过去了。

突然，那艘飞船撞上石阵、正要反射出去的一瞬，白的滑翔机从侧面撞了上来。飞船炸开，化作一片滑翔机风暴。

<span style="color:#df74b1">“什么？”</span>泽喊了出来。

<span style="color:#ed756b">“抓到你了。我在那条路线上留了一个符记，正好落在你看不见的位置。所以你的飞船边缘一过来，我就看到了。”</span>

泽闷哼一声。那已经是他挽救这盘棋的最后一搏。白的滑翔机又涌进来，把他西南角仅剩的两个符记也撕碎了。

泽点了认输按钮。

<span style="color:#df74b1">“这盘下得好。”</span>泽说。语气还谈不上真心，但比以往任何一次输给白时都要诚恳得多。

<span style="color:#df74b1">“你知道，全国赛上我需要你帮忙。”</span>

<span style="color:#ed756b">“乐意。只要你……”</span>

<span style="color:#df74b1">“嗯，我知道，你现在想去维里迪亚看看。”</span>

<span style="color:#ed756b">“总之，谢谢你那次锦标赛里把你的思路讲给我听。让我想了很多。”</span>

<span style="color:#df74b1">“那当然。”</span>

<span style="color:#ed756b">“你当然乐意回味当初打败我的那一刻，就像我刚才赢你这一盘也很痛快。”</span>

泽叹了口气。

<span style="color:#df74b1">“总之我得走了。昆高培的评议员登又叫我去见他。”</span>

---

泽走进那间长屋，立刻看见登和穆坐在对面。

<span style="color:#e58137">“谢谢你来。”</span>

<span style="color:#df74b1">“应该的。您推荐的那些基于哈希的签名我都看过了。那套构造很有意思，尤其是那些无状态的树套树结构。”</span>

<span style="color:#e58137">“你现在明白了吗？当初我看你下民本棋的风格，就知道你在这上面会有出息。”</span>

<span style="color:#df74b1">“我想我明白！”</span>

<span style="color:#e58137">“你真是了不起。不到一个月就把密码学讲座的三分之一赶完了，前两次测验还都拿了满分。我想不出有谁做得比你更好。”</span>

听到这句夸奖，泽眼里闪过一丝满足的光。

<span style="color:#e58137">“泽，你知道我为什么叫你来吗？”</span>

这时，泽想到了登这句话可能的一层意思，脸上那点高兴瞬间变成不安。

<span style="color:#df74b1">“您是要劝我全职做这个吗？比如，放弃民本棋全国赛？”</span>

穆笑了。<span style="color:#00bc96">“看来我猜错了——这一层你还是没懂。”</span>

<span style="color:#df74b1">“嗯？”</span>

<span style="color:#00bc96">“你想过没有，民本棋为什么这么郑重、有这么多仪式、祭司要进地牢待上好几天，还有那么多经费？”</span>

<span style="color:#df74b1">“它是一项运动。很多国家的运动都很受重视，经费也很充足。”</span>

<span style="color:#00bc96">“智力运动可不算。这类运动的观众不够多，光靠广告、国家荣誉这些名目，撑不起这么多经费。”</span>

<span style="color:#df74b1">“那到底是为什么？”</span>

穆往前倾了倾身。

<span style="color:#00bc96">“因为民本棋不只是一项运动。”</span>

泽怔住了。

<span style="color:#00bc96">“它是军事训练。”</span>

<span style="color:#00bc96">“这项运动存在的全部意义，也是我们如此支持它的原因，就是培养下一代的防卫者。”</span>

<span style="color:#e58137">“我们需要能在压力下快速思考、从战略层面思考的人。”</span>

<span style="color:#00bc96">“既要能与敌人较量，也要能与盟友合作，哪怕是跟自己合不来的盟友。”</span>

<span style="color:#e58137">“能理解战场的人——从战斗本身，上到大战略、资源与后勤，下到侦察、保密与诡计，直到最根本的熵。”</span>

<span style="color:#00bc96">“能应对规则突然变化的人。”</span>

<span style="color:#e58137">“既能事无巨细地管控，也能定下一个计划、放它自己展开的人。”</span>

<span style="color:#00bc96">“还有能用上最新技术——包括 AI——又懂得它的局限、能绕开这些局限的人。”</span>

这些领悟一下子全涌上泽的心头。他起初想问一个很基本的问题：为什么要把这事伪装成一项棋类运动，为什么不干脆建一支常规军队、照常规办法征兵？可这个念头刚一成形，他就已经知道答案：北极人会把全部精力用来针对任何那样的东西。民本棋之所以安全，只因为它伪装成一项纯粹的运动。但泽知道，即便如此，这层伪装也不可能永远安全。

<span style="color:#df74b1">“为什么现在告诉我这些？”</span>

<span style="color:#e58137">“因为我们现在既让你在密码学上用功，又让你继续打全国赛——总得给你某个理由。要是不告诉你，你可能会起疑，最后自己琢磨出来，然后干出蠢事，比如兴奋地把自己的发现嚷给十来个人听。”</span>

泽点点头。

<span style="color:#df74b1">“我不会告诉任何人。连芬也不说。”</span>

登和穆点了点头。

<span style="color:#00bc96">“等全国赛到了，你会需要一个熟悉你风格的陪练。”</span>

谁都没说出那个名字。也不必说。

<span style="color:#e58137">“谢谢你的支持。”</span>登答道。

<span style="color:#00bc96">“Dze go ba fau gie”</span>，穆补充道。

<span style="color:#df74b1">“Dze go ba fau gie。”</span>
