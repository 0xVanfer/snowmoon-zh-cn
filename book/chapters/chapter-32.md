# 第三十二章

<p class="dateline">梅尔丹，维里迪亚 · 3725年雨月12日</p>

格拉迪亚斯和塞拉并肩走在卡利马尔的那条小路上。到这时候，这条路他们已经走过几百遍了。小路被树木罩着，两侧都是石头房子。

左边，一名男子正爬上一架靠在树上的高梯。爬到梯顶，他开始拧下装在那里的监控摄像头。拧完，他随手把摄像头朝地上的箱子一扔——箱子在他下方好几米处。这一扔不偏不倚，正好落进箱里。摄像头撞上箱里已有的几十台摄像头，发出哐的一声脆响，格拉迪亚斯和塞拉听得清清楚楚。男子随即下梯。

他们继续往前走。路过一家商店——格拉迪亚斯记得，就在几个月前，这家店还匆匆把大半货品换成了应急储备口粮。这一次，占住前排货架的是一种北林特有的红花，居民们买它来庆祝该省解放。

店旁贴着一张广告：

<blockquote><p>本店现供应鲜水中的鲜水，直接从北极帝国核心领土缴获！</p><p>今天就尝尝最新的海德菲尔水，灌装自塔尔杜尔的泉眼！</p><p>尽享胜利的战利品。今天就买海德菲尔。</p></blockquote>

路渐渐钻进茂密的灌木丛，再往前是一条空中步道，底下是繁忙的高速公路。左侧能看见一座覆满树木的山。几栋约15层高的公寓楼从树梢上高高探出，外形和装饰像放大的中世纪城堡塔楼，只是侧面窗户多得多。

过了空中步道，路钻进了隧道，格拉迪亚斯和塞拉来到一个 Y 字形路口。他们向左拐，往前走，直到小路重新回到地面，再向右拐。格拉迪亚斯看了看手表上的导航。他其实从没走着去过议会。

20分钟后，他们到了那栋巨大的圆形建筑。格拉迪亚斯把手表贴上绿色圆圈，门开了。楼里的路线他记得很清楚：直走，右拐，再直走，左手第三扇门。

他又贴了一次手表，门开了。

韦尔多和泽都坐在办公室里。两人一齐转头看向格拉迪亚斯和塞拉。

<span style="color:#a38af2">“格拉迪亚斯，塞拉，欢迎回来！”</span>韦尔多热络而亲切地招呼道。

<span style="color:#be9b00">“韦尔多，又见到你真好！”</span>

<span style="color:#a38af2">“请坐，请坐。”</span>

一台机器人滑进房间。

格拉迪亚斯转头看了机器人一眼。<span style="color:#be9b00">“dia jie fe kai ja cu dze kai lin pan”</span>，他一字一句、刻意咬清字音地对机器人说。

机器人嗡了一声，出了房间。

<span style="color:#a38af2">“厉害，格拉迪亚斯。连我都做不到。”</span>

韦尔多沉默了片刻，又开口。

<span style="color:#a38af2">“好吧，我承认我露怯了。dze kai lin pan 到底是什么？”</span>

<span style="color:#df74b1">“菜和饭。”</span>

<span style="color:#a38af2">“啊对，绿植线面包。”</span>

<span style="color:#a38af2">“对了，泽，我们什么时候开始用光尺取代米？”</span>

<span style="color:#df74b1">“芬跟我说，班孙培正忙着把泽国的隐私和安全习惯全面提到新标准上。大概10天后，他和几个人真的要来维里迪亚，看看能不能帮你们也把这一块补上。”</span>

<span style="color:#df74b1">“不过我猜也不用等他们。你要是喜欢光尺，今天就可以用起来。”</span>

<span style="color:#a38af2">“看来他们说得对。换成光尺不是眼下最要紧的事。”</span>

韦尔多的语气忽然严肃起来。

<span style="color:#a38af2">“这个月有很多人在庆祝。一个世纪以来，北极帝国第一次被打败。北林解放了。塔尔杜尔也已经有不少人接受了我们的条件，帮我们把缴获的北极技术开放出来，好让我们真正从中受益、学到东西。”</span>

<span style="color:#a38af2">“但别忘了——这只是第一个回合。而且就算这一个回合，我们也没有全赢。”</span>

<span style="color:#a38af2">“北极人丢了北岸，丢了塔尔杜尔，但保住了红郡。他们在技术上失去了一些领先，可过去这几个月我们看清了，他们在别的技术领域进步飞快。”</span>

韦尔多叹了口气，接着往下说他那番提醒。

<span style="color:#a38af2">“我们以为自己拥有的隐私，其实并不存在。数字世界里还行——网络安全和密码学如今非常强，但别忘了，语言模型永远会以普通软件所不具备的方式被攻击。物理世界就难得多。物理世界里的信息，从根上就更容易漏出去。就连我们在键盘上敲下的一次按键，也有几十种途径泄漏到外面的世界。我们可以努力去对抗这一点——尤其在自己的私人空间里——但能做到什么程度，是有上限的。”</span>

<span style="color:#df74b1">“听说已经有一批泽国的新摄像头在运来的路上，内置了硬性保证，能传什么、不能传什么都写死在里面。维里迪亚国立大学正在琢磨检查它们的方法，好像想直接照搬泽国的做法。”</span>

<span style="color:#54a1f9">“哦，原来是这么回事？我们来的时候在卡利马尔看见有人拆了100台摄像头。”</span>

<span style="color:#df74b1">“看来是。”</span>

格拉迪亚斯决定换个话题。

<span style="color:#be9b00">“你觉得我们的政府怎么样？”</span>他问韦尔多。

<span style="color:#a38af2">“掌舵会管用，合议庭管用，图谱资助一直也没问题。可凡是更透明的那部分，全都垮了。照这个趋势，我猜政府往后做的每件事都会变得更私密。更数字优先，更多封死的隔信室，更多隐私袍。”</span>

韦尔多叹了口气，对他所预言的这番局面，显然至少有些不满。

<span style="color:#a38af2">“这里有一种根本性的张力，我们的政府体制从它诞生的第一天起就在跟它较劲。在一个彼此连通的世界里，一个政府怎么可能既对本国公民负责，又不必同时对内有钱有势的利益集团、对外部的敌人也‘负责’？这两拨人都盯着最薄弱的环节下手，把它孤立起来，施压、扭弯，让它为自己的目的服务。”</span>

<span style="color:#a38af2">“我们得不断改进自己对透明和问责到底意味着什么的理论。在政府眼下这一版里，答案是一端的遴选程序，加上另一端的宣谕使。到了下一版，也许就得换别的了。我觉得那一定会牵扯到类似银聊民调的东西，或者某种带宽更高的机制，用来搞清人们的目标；还要有涉及 AI 的机制，来想清楚怎么达成那些目标。”</span>

<span style="color:#a38af2">“泽，你怎么看？”</span>

<span style="color:#df74b1">“AI 是这场讨论的起点，不是答案。什么样的 AI？怎么训练？谁来训练？我们给它什么指令？谁给 AI 喂信息，谁又介入 AI 的思考过程去帮它？”</span>

<span style="color:#a38af2">“那你会怎么回答？”</span>

<span style="color:#df74b1">“我会先退一步，想想问题到底出在哪儿。我想我已经发现了一个。维里迪亚这些机构按今天的样子，并没有真正内置‘预测未来’这个概念。它们谈的全是当下，是当下的民意。”</span>

<span style="color:#df74b1">“没有任何一个位置要求你站起来说——如果我们做 X，那么就会发生 Y——说对了你就往上升，说错了你就往下掉。最接近的是见习官，他们必须预测监审官。可就算在那儿，他们预测的也不是真实世界，而是监审官。所以那还是在预测别人的看法。你把人和人对齐了，却没有把人和现实对齐。”</span>

<span style="color:#df74b1">“那正是 AI 能做得很好的地方——也正是 AI 已经为我们**做到**的地方。但我觉得不该只挑一个 AI，而应该让它们之间有某种公开竞争。AI 应该是棋手，不是棋局。让不同的人选不同的 AI、用不同的方式跟它们协作，再让它们为目标负责。”</span>

<span style="color:#a38af2">“一个社会该有目标吗？”</span>

泽盯着韦尔多。

<span style="color:#df74b1">“什么意思？”</span>

<span style="color:#a38af2">“说到有目标，北极人比我们任何一个国家都强。他们清楚知道自己要什么，一心一意去实现。你要是造一台完美的目标执行机器，造出来的就是北极人。”</span>

<span style="color:#df74b1">“所以才需要另外那个部件——能把不同人的目标汇集起来、加在一起，这样你才知道自己实现的是人民真正的目标，而不是某一个皇帝的目标。”</span>

<span style="color:#a38af2">“可要是你想出来、写在纸上的任何目标，最后都长成那副样子呢？”</span>

<span style="color:#df74b1">“什么意思？”</span>

<span style="color:#a38af2">“要是人本来就是这样呢——我们并不完全知道自己想要什么，而任何想把它定死成一块的尝试，只要推得够远，终究会崩掉？我们的评则就是这样：它们能管用一阵子，最后总会被人钻空子；我们就调整评则，然后再来一遍。要是这根本躲不掉呢？”</span>

<span style="color:#df74b1">“那还有什么别的办法？”</span>

<span style="color:#a38af2">“想一个装满水的湖。湖里的每一个水分子都各自行动。没有总体规划，只有万亿个分子做着万亿个梦。这个湖自有它的和谐与平衡，我们都看得见。但那不是因为有人在强迫这种平衡发生，而是因为只要湖面的任何一处哪怕短暂地低于别处，重力就会把水引过去，各处的高度便又齐平了。”</span>

<span style="color:#a38af2">“但同样地，冬天来临时，这些分子会聚到一起，结成厚厚的晶体，变成无法穿透的冰。”</span>

<span style="color:#df74b1">“你物理学得不错。”</span>

<span style="color:#a38af2">“我女儿刚开始学化学，跟我讲了不少。她的朋友觉得她太用功，我倒一直鼓励她——我跟她说，只要肯下功夫，有一天她也能像你一样。”</span>

泽脸红了。

<span style="color:#a38af2">“所以我想，理想就是这样：一个能行日常之善、却不作帝国与征服之恶的社会。既能抵抗北极帝国，又不至于自己变成那样的帝国，而是一步一步和平地繁荣起来。”</span>

<span style="color:#a38af2">“想要什么，很难有一致意见；不想要什么，就容易一致得多。我觉得我们的一切都建立在这份不对称上。冬天，我们朝同一个方向对齐，能结成晶体，能防御、能反击。夏天，我们像水一样流动。去中心化的力量——市场、开放的思想讨论、开放的科学、文化与法律——在无人主导的情况下，让我们那万亿个梦想的万亿份力量相加多于相减。我们会去调整它们的规则，但只小心翼翼地、慢慢地调。这样几十年又几十年下来自然而然取得的温和进步，比满足任何目标都更值钱。”</span>

<span style="color:#be9b00">“那要是有时候，湖的不同部分必须同时既是水又是冰呢？”</span>

<span style="color:#a38af2">“也许吧。”</span>

<span style="color:#54a1f9">“那要是湖面每一点都跟别处完全等高，本身也是一种我们不想要的整齐划一，有时候我们不如结成雪球、让它们漂着，反倒更好呢？”</span>

<span style="color:#a38af2">“那也可能。”</span>

<span style="color:#a38af2">“塞拉，你觉得我们该往哪方面多使点劲？”</span>

<span style="color:#54a1f9">“北极人有竞争——他们在意谁强谁弱，鼓励人们互相挑战、拼命往上爬——但他们不懂合作。他们是冰，却没有水。维里迪亚有合作，可我们也许不懂竞争。我们能当水，却还不知道怎么当冰——就连我们的水，也不总是流得如我们所愿。其实我觉得，真正想明白怎么同时拥有两者、并让它们彼此服务的，是泽国。我们该多向他们学。”</span>

她深深叹了口气。过了一会儿，韦尔多又开口。

<span style="color:#a38af2">“这些都是好想法。”</span>

<span style="color:#a38af2">“泽，你愿意留下来，帮我们琢磨琢磨其中一些问题吗？”</span>

泽想了一会儿。

<span style="color:#be9b00">“穆和苏肯定能把昆高培打理得很好”</span>，格拉迪亚斯插话道。

<span style="color:#df74b1">“当然愿意！不过你也许会发觉，芬比我更能帮上忙。”</span>

<span style="color:#a38af2">“那就多谢了。你知道，议会现在明白了，他们现有那套思路已经到头了。很多议员辞了职。还留在里面的——比如我——想要新想法。我们愿意听。”</span>

韦尔多站起身，慢慢走到办公室侧墙上印着的一幅世界地图前。

<span style="color:#a38af2">“这就是我们的世界。9000万人。格拉迪亚斯、塞拉、泽，你们有没有想过，如果这里有9亿人，或者90亿人，会是什么样子？”</span>

<span style="color:#be9b00">“没想过。你为什么这么问？”</span>

<span style="color:#a38af2">“人口越多，新技术的发明就越快。中世纪之所以那么停滞，今天之所以走得这么快，原因都在这里。但不管人口多大，每个人适应技术的速度还是一样的。也许我们之所以能适应得这么好——根除计算机病毒，给一切加上这么多隐私和可验证性，把社会优化得这么美、这么健康——只是因为这里没有90亿人把技术推得更快、把那个必须接受技术的社会搞得更加复杂。”</span>

<span style="color:#be9b00">“有意思。你觉得有一天我们会有90亿人吗？”</span>

<span style="color:#a38af2">“不是有一天，是很快。而且不是人，是机器人。也不是90亿，是9万亿。”</span>

<span style="color:#a38af2">“我担心的就是这个。AI 真的会改变一切。到目前为止，进步还算温和，没有人失业，感觉更像是所有人都被提拔成了管理者——有时是修理工。但到了某个时刻，一旦 AI 几乎能做人类能做的一切，哪怕效率只有百分之几，我们的人口就不再是约束了。”</span>

<span style="color:#be9b00">“那我们怎么办？”</span>

<span style="color:#a38af2">“这个嘛，如果北极人一直领先下去，我们其实没多少实力来回答那个问题。”</span>

<span style="color:#a38af2">“要想重新回到平衡，我们就得更擅长渗进他们那边。对他们的社会和技术多看出些门道，确保他们每有一点进展，我们都能知道。弱者要隐私，强者要透明。有塔尔杜尔那些人帮忙很好，也希望红郡那边假装投靠北极人、其实愿意多给我们递情报的，远不止德鲁因一个。”</span>

<span style="color:#df74b1">“博弈论里有个已知的结论”</span>，泽插话道。<span style="color:#df74b1">“如果两个玩家困在一局既有合作又有竞争的博弈里，那么只要他们至少能部分读懂对方的心思，就能把双方的合作抬到比原来更高的层次。也许那才是该指望的结果。随着时间过去，我们会更了解彼此，会互相学习，最后真正更懂对方。”</span>

<span style="color:#a38af2">“我没这么乐观。北极皇帝很不痛快。他现在拿我们没办法，但肯定在盘算。会有下一个回合。可能是5年后，也可能是20年后。只要我们在技术上至少不掉队，就能活下去。”</span>

<span style="color:#be9b00">“你觉得我们该设法拖慢他们吗？”</span>

<span style="color:#a38af2">“把他们一个世纪以来对泽国做的事，照样对他们做一遍？倒也不算最坏的主意。”</span>

泽叹了口气。

<span style="color:#df74b1">“我们能在他们的压力下继续前进，他们就一定能在我们施加的任何压力下继续前进。”</span>

<span style="color:#df74b1">“你知道，这一切走到后期会变得很疯。到了某个时候，我们终究会有虫子、苍蝇那么大的无人机，在地下钻、在空中飞、在海里游。我们会有现在根本想象不出的新型基因工程生命——既为和平，也为战争。我们中的一些人也许会被上传，住在计算机里。不是今年，也不是接下来几年，但100年内一定会。”</span>

<span style="color:#df74b1">“也许200年后就会稳定下来。到那时我们已经弄清每一种尺度上最理想的无人机形态：最大的有飞机那么大，甚至是漂浮在太空里的空心小行星；最小的则小到跟病毒之间再没有空隙。一旦我们顶到天花板，就不会再有更强的力量能打败它们。只剩下庞大的分布式免疫系统，保护我们的星球、我们的动物、我们的树木，还有我们自己。我们会更明智，几乎所有人都会选择和平而不是战争，不肯选的人也没有任何途径把意志强加于人。每个人就过自己想过的生活。”</span>

<span style="color:#54a1f9">“我只盼着能有和平”</span>，塞拉补了一句。<span style="color:#54a1f9">“这一大堆问题：基因工程、上传、走向星辰——要是我们因为害怕，每一步都赶着走，我不觉得能得出对的答案。我不确定自己想不想上传。但一年前，我也不确定自己想不想活过100岁。这些事都该是我们深思熟虑后的选择，也该尊重那些跟我们选得不一样的人，而不是为了在战争里活下去而仓促做出的决定。”</span>

韦尔多又接上了话。

<span style="color:#a38af2">“我们也许会有那种和平，也许不会。可以盼望最好的结果，但也得为所有可能做好准备。”</span>

<span style="color:#df74b1">“你知道，几天前白跟我说，她在考虑去塔尔杜尔待一年——正是为了更好地理解北极人怎么想，看看能不能找到通往那种和平的路。”</span>

<span style="color:#a38af2">“这听着比德鲁因干的事让人放心多了。我支持她。”</span>

门开了。一台机器人滑到格拉迪亚斯身边，端着他的茶，还有米饭和蔬菜。格拉迪亚斯双手接了过来。他向机器人道了谢，机器人又滑出了房间。

<span style="color:#a38af2">“想上楼去屋顶看看吗？”</span>韦尔多问。

<span style="color:#df74b1">“好啊”</span>，泽答道。

格拉迪亚斯、塞拉和泽站起身。韦尔多出了房间，沿着走廊往前走。3人跟在后面，格拉迪亚斯仍是一手端着茶，一手端着他的饭。

韦尔多领他们上了一段楼梯，走到一扇自动打开的门前。他们走了出去。

左边是梅尔丹的主要商业区。各式风格的建筑都有：有些在美学上模仿某种更古老、近乎中世纪的东西，另一些则明明白白地现代、未来。那栋像飞机的建筑在楼群里格外扎眼，稍微煞了点风景。只有你自己站在地面上的时候，树木才遮得住它，格拉迪亚斯想。

商业区再往左，是灰紫色的大梅港。整个大梅港是块将近1公里见方的区域，从他们站的地方能清楚看到里面许多建筑。而在商业区的右缘，格拉迪亚斯辨认出了那座大型演唱会场馆。

正前方是卡利马尔区。从他们站的地方看去，那跟一片森林差不了多少。高大的树木盖住了大半区域，只有几栋建筑勉强从树顶探出一点。格拉迪亚斯飞快扫了一圈，认出了银聊的总部。

右边是那座覆满树木的山。他们已经上到半山，比梅尔丹大部分地方高出约40米。但在他们右侧约200米处，山势才开始真正向上攀升。从他们所在的位置，那种仿中世纪城堡塔楼的公寓楼只能看见大约一半。格拉迪亚斯想，山凑近了看，要大得多、也压人得多。

<span style="color:#be9b00">“我喜欢这里的绿。要我在北边待着，几个月见不到绿、只有雪，我大概受不了。”</span>

<span style="color:#be9b00">“再说，梅尔丹是我的家。”</span>
