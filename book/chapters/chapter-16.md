# 第十六章

<p class="dateline">梅尔丹，维里迪亚 · 3724年火月25日</p>

格拉迪亚斯拉开隔间的隔板走了进去，又反手把隔板拉上。他气冲冲地在德尔瓦特对面的长凳上坐下。

<span style="color:#be9b00">“你要解释的事情可不少。”</span>

德尔瓦特低头看着桌面，一脸懊悔。

<span style="color:#e58137">“听着，格拉迪亚斯，你是对的，我错了。我恨维里迪亚政府和文化里无处不在的干预主义，结果被这份恨蒙住了眼，忘了有些事本来就是政府该管的，国防就是其中之一。”</span>

<span style="color:#be9b00">“我生气不是因为这件事。”</span>

德尔瓦特一惊，抬起头。

<span style="color:#be9b00">“我是说，那算一个原因，但远远不是主要的。”</span>

<span style="color:#e58137">“那主要的是什么？”</span>

<span style="color:#be9b00">“到底出什么事了？你是什么人？你在跟谁干？”</span>

德尔瓦特叹了口气，沉默了片刻，然后往前探身。

<span style="color:#e58137">“好，我解释。”</span>

<span style="color:#e58137">“干这件事的教条主义者不止我一个。我和另外一群人——我并不认识他们——在替银聊做事。”</span>

<span style="color:#e58137">“那些评则让我们很窝火——就因为一群人在我们平台上讲粗俗笑话，我们的税就往上涨。我们想让银聊成为一处避难所，躲开那股正在吞掉维里迪亚大部分地方的平庸乏味。我们想让它成为一个连海德菲尔、甚至恐结都能受到欢迎的地方。”</span>

<span style="color:#e58137">“于是我们决定自己动手。有组织地做点事，把政治往更好的方向拽一拽。直接向掌则人陈情。”</span>

<span style="color:#e58137">“现在我才明白，这一切有多天真。如果我们挡住了乏味，代价却是让北极帝国得以接管，并造成严重得多的祸害——先落在红郡，之后落到全世界——那这件事就不只是不值，而是彻底的灾难。”</span>

格拉迪亚斯叹了口气。他对德尔瓦特仍然气极了，只是这股怒气里，如今掺进了一丝同情。

一个机器人滑到他们跟前，端来一份沙拉、一根长方形的营养棒和水，供两人吃喝。

格拉迪亚斯和德尔瓦特都先端起自己那盘食物，放到桌上。然后格拉迪亚斯拿起杯子，一口气喝掉大约半杯水。德尔瓦特也一样。

两人默默吃起来。几分钟后，话头又续上了。

<span style="color:#be9b00">“你现在想让我做什么？”</span>格拉迪亚斯问。

<span style="color:#e58137">“显然，现在别让那条评则把军事相关产品排除在外。你甚至可以提高税率档，不过你这么调也只能起一点小作用——真正重要的杠杆在图谱资助那边。”</span>

<span style="color:#e58137">“不过我还有个主意，你可以去做。”</span>

<span style="color:#be9b00">“什么主意？”</span>

<span style="color:#e58137">“我觉得你该去一趟泽国。”</span>

<span style="color:#be9b00">“我？去泽国？为什么？”</span>

<span style="color:#e58137">“北极这一整套问题，他们显然比我们维里迪亚人看得清楚得多。去研究他们，跟他们学，看看你能带什么东西回维里迪亚。”</span>

<span style="color:#be9b00">“你都已经这么不可信了，我凭什么听你的？”</span>

<span style="color:#e58137">“嗯，千万别只听我的。去问问你最亲近的朋友和顾问，看他们怎么说。”</span>

---

格拉迪亚斯走在卡利马尔那条他常走的路上。路两旁照例是石屋，头顶树冠成荫。可那天热得不寻常，阳光透过树冠漏下几缕，把他连人带隐私袍都晒得暖烘烘的，他也微微出了汗。

他路过其中一幢房子，记得那家卖维里迪亚传统食品。这一次，海报上又匆匆贴了一张告示，推销几款套装：味道好、营养全面、能长期保存，足够撑过30天。

他点了点手表，打给莫夫。

<span style="color:#be9b00">“我跟德尔瓦特谈过了。”</span>

<span style="color:#00bc96">“谈得怎么样？”</span>

<span style="color:#be9b00">“你说对了，确实有人在有组织地做这事。原来——至少他现在这么说——他一直在替银聊做事。”</span>

<span style="color:#00bc96">“银聊？我还以为会是个更邪恶的公司，比如蓝鲸。”</span>

<span style="color:#00bc96">“想想也说得通，一个半月前我偷听到的那段对话，对方多半就是银聊的人。”</span>

<span style="color:#be9b00">“所以他现在想让我去泽国。”</span>

<span style="color:#00bc96">“泽国？去干什么？”</span>

<span style="color:#be9b00">“他说我们维里迪亚人能从他们身上学到很多东西。你觉得这话对吗？”</span>

<span style="color:#00bc96">“你知道，红郡被占的那天，我有个朋友跟我提过类似的话。他觉得该去的是**我**，去看看他们的秘密社团是怎么运作的之类的。”</span>

<span style="color:#be9b00">“你知道，塞拉现在有个从那儿来的朋友，她上次跟我说，那人在民本棋排名里升得飞快，已经打进全国赛了。所以我要真去了，说不定还真能学到点东西。”</span>

<span style="color:#00bc96">“是啊，我完全能理解这事的吸引力。维里迪亚人确实该更了解外面的世界，尤其机构里的人——掌舵会、合议庭、议会，所有这些。”</span>

<span style="color:#00bc96">“给我几天时间想清楚。”</span>

<span style="color:#be9b00">“嗯，那几条评则的表决分别在8天后、12天后和16天后，所以不管怎样，你都有这段时间可以想。”</span>

格拉迪亚斯顿了顿。

这时，他正走过离家不远的那家餐馆——他平时常在这儿吃点东西、喝两杯。透过窗户，他看见费布里克在吃饭。

<span style="color:#be9b00">“我也会想想，”</span>他终于说出口，然后挂断了通话。

---

格拉迪亚斯走进餐馆，几乎立刻摘掉隐私袍的面罩，把前襟的拉链拉开一半。反正吃饭时也遮不住多少，何况他在大太阳底下走得一身汗。他在费布里克身边坐下。

<span style="color:#ce9200">“哦，格拉德叔叔，又在这儿见到你，真高兴！”</span>

<span style="color:#be9b00">“我也高兴见到你！”</span>

格拉迪亚斯注意到费布里克一直在看屏幕。上面正直播一场翔球比赛。

格拉迪亚斯由着自己看了一分钟比赛。镜头正跟着领先的那名黄衫球员，他正在追一颗红球。

突然，不知从哪儿冒出一名紫衫球员，一下把他撞到一边。黄衫球员翻滚出去，随后在5米开外自动稳住身形。

镜头切到那名紫衫球员。他在半空中接住一颗蓝球。另外两名黄衫球员朝他飞扑过来。还没等他们贴近，他就把蓝球抛向队友。队友稳稳接住，开始向前飞。

镜头转向一根高高矗立的杆子，杆顶架着一块圆板，板上立着10个排成三角形的黄色球瓶。持球的那名紫衫球员进入画面。一名黄衫球员急速飞到位，卡在他和球瓶之间。

紫衫球员突然把蓝球高高抛向空中，与此同时另一名黄衫球员撞了上来。

蓝球从守瓶的黄衫球员头顶约5米高处飞过，落在圆板上，撞倒了3个球瓶。

屏幕上的记分板跳了一下。

紫队的蓝球得分刚从20涨到23，合计得分从1540涨到1771——足以反超对手。

突然，就在那名刚击倒球瓶的球员还在庆祝时，一颗绿球砸在他后背上，颜料在他身上炸开。

记分板又变了。

<span style="color:#ce9200">“你得承认，现在的计分系统是真好，”</span>费布里克大声说。

<span style="color:#ce9200">“我记得我比现在小得多的时候，他们一直在调红球、击倒球瓶、击中球员3种得分的比例。可怎么调都跳不出一个局面：理性的做法就是只盯着其中一项。”</span>

<span style="color:#ce9200">“就算调对了，不到一年，打法又跟着变，局面再次失衡。”</span>

<span style="color:#ce9200">“我觉得唯一的出路是把得分改成相乘。这样一来，3种得分你基本都得顾上。”</span>

<span style="color:#be9b00">“或者拼尽全力，让对手其中一项一分都拿不到，”</span>格拉迪亚斯插了一句。

<span style="color:#ce9200">“啊对，一开始就有几个人试过，”</span>费布里克回答。<span style="color:#ce9200">“抓着红球超过30嘀嗒早就被禁了很多年，那招在还是按加法计分的年代，对红球较弱的一方来说就已经很好用。但有支队伍试的是：开局很早就敲倒一堆球瓶，然后把大部分球员都派去守自己的球瓶，守到终场。”</span>

<span style="color:#ce9200">“结果根本不管用。人在小型飞行器上，再挤也挤不到哪儿去，不管你怎么弄，对面总能偷偷塞几个蓝球进来。你要是真把人都挤到球瓶周围一个点上，就成了绿球的活靶子。”</span>

<span style="color:#be9b00">“你是想上场打？”</span>格拉迪亚斯问。

<span style="color:#ce9200">“没有，不过我刚跟兹文聊了一堆这个。这里面的数学，几乎跟真打一场一样好玩！”</span>

格拉迪亚斯和费布里克都把注意力转回了食物。

<span style="color:#be9b00">“对了，莉莉最近怎么样？”</span>格拉迪亚斯问。

<span style="color:#ce9200">“这几个月她其实好转了一些。几天前她跟我说，最近一次公民课测验考了70%。她好像开心了点，玩手持终端上那个游戏也更投入了。”</span>

<span style="color:#be9b00">“你知道是什么游戏吗？”</span>格拉迪亚斯问。

<span style="color:#ce9200">“她也不给我看。”</span>

格拉迪亚斯和费布里克都接着吃了起来。几分钟后，两人都吃完了。

<span style="color:#ce9200">“这次你记得把齐普币拿出来了？”</span>费布里克打趣地问。

<span style="color:#be9b00">“嘿，我可能犯很多错，但同样的错我不会犯两次，”</span>格拉迪亚斯回了一句。

<span style="color:#be9b00">“对了，费布里克，谢谢你提醒我——我得试一下我这笔钱包的恢复流程，”</span>他对着颈带低声说。

<span style="color:#ce9200">“要我帮你签一笔测试交易吗？”</span>

<span style="color:#be9b00">“好啊！你想拿什么当测试？”</span>

<span style="color:#ce9200">“不知道，买一瓶海德菲尔？”</span>

<span style="color:#be9b00">“买一瓶海德菲尔？直接从毕生积蓄的钱包里掏？”</span>格拉迪亚斯难以置信地问。<span style="color:#be9b00">“那些广告也真把你拿下了，是吧？”</span>

<span style="color:#ce9200">“嘿，是你先问我的！”</span>

<span style="color:#be9b00">“行吧……我来发起操作。”</span>

格拉迪亚斯对着颈带低声说起来。眼角余光里，他看见费布里克跑去了什么地方，不过他太忙，没空去想是哪儿。

几个嘀嗒后，费布里克的手表震了。

<span style="color:#be9b00">“塞拉，我回来了！”</span>

<span style="color:#54a1f9">“格拉德！”</span>

<span style="color:#be9b00">“我有个挺有意思的消息。”</span>

<span style="color:#54a1f9">“什么消息？”</span>

<span style="color:#be9b00">“我有可能很快要去一趟泽国。”</span>

塞拉盯着他。

<span style="color:#54a1f9">“为什么？”</span>

<span style="color:#be9b00">“我跟莫夫聊过这事。他觉得维里迪亚人——尤其是掌则人、掌舵会以及整个体制里的人——都能从那边学到很多东西。”</span>

<span style="color:#54a1f9">“这事我说不好……眼下时机不好。这趟泽国之行，你来跑未必能用得最值。而且接下来这几个月，掌则人正需要有强手替他们引路。”</span>

<span style="color:#be9b00">“北极的事，其实更多是军方和议会的责任，也许还有图谱资助。而且……要是你能把我引见给泽，我这趟说不定就不算白跑？”</span>

塞拉沉默下来，想了片刻。

<span style="color:#54a1f9">“如果莫夫觉得这主意好，那就行。但请你先做功课。在图谱资助或者议会里找个人——谁都行——聊聊，好让你大致知道这趟值不值得去；要是真去，又该怎么让这趟行程尽量有用。”</span>

<span style="color:#54a1f9">“不过说真的，这事你得好好想。”</span>

<span style="color:#54a1f9">“你要真去，我当然会把你引见给泽，还有白。”</span>
