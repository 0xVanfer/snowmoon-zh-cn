# 第二十八章

<p class="dateline">梅尔丹，维里迪亚 · 3724年霜期15日</p>

泽、登、白、穆4人围坐在会议室的一张桌旁。

门口传来一声蜂鸣。他们立刻停住话头，等着看是谁进来。

门开了。是韦尔多。

<span style="color:#a38af2">“有位访客。”</span>

<span style="color:#df74b1">“是谁？”</span>泽问。

<span style="color:#a38af2">“一位将军。准确说，是我少数几个敬重的将军之一。我用翡翠跑了一遍分析，回来的结果全是对他的好评。”</span>

<span style="color:#df74b1">“他想干什么？”</span>

<span style="color:#a38af2">“谈谈。关于眼下这桩案子。”</span>

<span style="color:#ed756b">“当然，我们很乐意跟他谈。”</span>白答道。<span style="color:#ed756b">“他现在就在外面？”</span>

<span style="color:#a38af2">“在。”</span>

<span style="color:#ed756b">“那就让他进来。”</span>

一个中年男人走进房间。他穿的衬衫几乎像是专门设计来拿捏这个分寸的：看着既像维里迪亚的传统军装，又舒服得能当日常衣服穿。

<span style="color:#23ba7d">“我是莱克托，”</span>他朗声说道，<span style="color:#23ba7d">“很高兴见到各位。”</span>

泽正要开口回应，登却示意他别说话。

<span style="color:#e58137">“我是登，这几位是泽、穆、白。欢迎。”</span>

莱克托走进来，在一把空椅子上坐下。

<span style="color:#23ba7d">“听着，”</span>他开口道，<span style="color:#23ba7d">“我想弄明白，你们到底在想什么。”</span>

<span style="color:#23ba7d">“维里迪亚历史上，头一回有人想让合议庭把政府高层官员免职。这看着像疯了一样。我明白民众有情绪，可你们想撤掉的是整个军方领导层。这么干，拿不到一支能打的军队。”</span>

他停顿了一下。

<span style="color:#23ba7d">“但话说回来……我明白民众有情绪。那些银聊民调，我们也和大家一样看到了。”</span>

<span style="color:#23ba7d">“所以，你们是怎么想的？”</span>

登开口了。

<span style="color:#e58137">“营救塔芬德尔的那次行动，你了解吗？”</span>

<span style="color:#23ba7d">“当然。这段时间我们一直在拼凑事情的经过。”</span>

<span style="color:#e58137">“是我们干的——昆高培。我们和两家自由城防务公司合作，把他救了出来。”</span>

莱克托惊得张大了嘴。

<span style="color:#23ba7d">“等等，你们人就在这里？来了多少？”</span>

<span style="color:#e58137">“几十个。我是最高评议会的评议员之一。那边的泽和穆两位，当初都跟我一起亲自指挥了这次行动。”</span>

<span style="color:#23ba7d">“原来如此……”</span>

莱克托顿了顿。

<span style="color:#23ba7d">“那你们的计划是什么？亲自接管维里迪亚的无人机机队，拿它把北岸夺回来？”</span>

<span style="color:#e58137">“我知道这计划不太体面。但你得明白，我们走投无路了。北极帝国在扩张。他们显然打算先拿你们开刀，再对付我们：你们技术更先进，我们防守准备更充分。所以我们判断，北极人想在一年内把维里迪亚彻底打垮，也许还更快。接着他们会逐个拿下联合城邦，然后南下清掉梅萨利亚和哈拉格米尔，或者干脆炸平了省时间。到那之后就只剩他们对我们。凭现有家底，我们能守得不错，可最先进的技术，我们实在依赖你们太深。所以我们必须站出来——一起站出来，就现在。”</span>

<span style="color:#23ba7d">“军队不是一辆新车——不能你想开走就直接开走。我们的士兵，包括各级指挥官和将军，在一起共事、一起训练了多年。维里迪亚的后勤，他们摸得门儿清：我们能造多少新无人机，造这些要什么条件，要是非得把那些翔球小型飞行器改成无人机，又能做到什么程度。他们有一千多名无人机飞手，还有成千上万的各种保障人员。就凭你们这几十个顾问，几乎每架无人机都得靠 AI 自己飞。它们会迷航，一有机会就会被北极人骗得团团转。”</span>

<span style="color:#23ba7d">“我知道我们在北岸彻底失败了，但你们不能把我们已经建起来的一切全扔掉。连指挥体系也一样——那是他们干了多年、早已长在里面的东西。你不能一把撕掉、再换一套，还指望结果能好。”</span>

白觉得话题正在跑偏，看到机会插了进来。

<span style="color:#ed756b">“莱克托，”</span>白开口道。<span style="color:#ed756b">“我们其实没打算把维里迪亚军方的最高三级全部清零。就算我们真能明天就把1,000名顶尖的民本棋选手全带过来，让他们成功操控你们所有无人机机队，后勤也莫名其妙自己理顺了，这桩官司光走完程序也要三个多月。我们没那么多时间。所以那从来不是我们的计划。”</span>

<span style="color:#23ba7d">“那你们原本的计划是什么？”</span>

<span style="color:#ed756b">“嗯，我们想要一个像你这样的人站出来帮忙。”</span>

莱克托没有作声。

<span style="color:#ed756b">“哪怕是挨骂最多、最招人恨的机构，也从来不像社交媒体渲染的那样无可救药、一无是处。这点我们明白。但与此同时，它们确实会卡在有害的状态里。而你们的处境最难：眼下正是要做平战转换的时候，偏偏又赶上不少将军很可能正被北极人收买或要挟。我们知道这是真的——我们动过手脚的那些监控摄像头，已经抓到好几个了。所以我们不想把军方清零，但也清楚，它不能照原样待着。”</span>

<span style="color:#ed756b">“所以我觉得，这里有个让你站出来的机会。各方都敬重你。你和泽说话的时候我查过了：不同政治立场的人、军方和议会里的人、各种性格类型的人，给你的评价都一致地高。我觉得你可以考虑向议会提议，由你接手、掌管全局。我们可以在你的体系里跟你配合。”</span>

登、泽、穆立刻点头。这番话不在他们原本的计划里，但他们都看得出，这才是该顺势转向的正路。

莱克托沉吟片刻，又开口了。

<span style="color:#23ba7d">“你们在这儿这件事，一直捂得很严。就连那些盼着昆高培来掌管维里迪亚军方、在民调里投了赞成票的人，也都只当这是个幻想。要是我开始主张，自己能在你们的支持下掌管全局，这不会暴露你们吗？就算是闭门会议，如果议会真像你们说的那么腐败，消息一样会漏回北极人那里。”</span>

这次是穆开口。

<span style="color:#00bc96">“别跟他们提我们。我们手上有几个针对北极无人机的漏洞利用，可以给你们。这些漏洞对北极人自己早就过时了——所以就算北极人知道了，反而更好，能让他们放松警惕。但这些漏洞用在两个月前你们从北岸弄回来的那架受损无人机上，会很灵。功劳都算你的。”</span>

莱克托又愣住了。他们连那架受损无人机都知道？他们是怎么把维里迪亚渗透得这么……彻底的？如果昆高培能做到这一步，那北极人……

<span style="color:#00bc96">“哦，我们还能告诉你其中一个收受贿赂的将军是谁。我们有确凿证据——他和北极间谍谈话的监控录像。”</span>

<span style="color:#00bc96">“他们谈得太勤，还挑错了隔间。”</span>穆咧嘴一笑。

<span style="color:#ed756b">“我们会把手上掌握的信息打包给你。计划你自己定。毕竟那将是**你的**军队，**你的**计划”</span>，白补充道。

---

格拉迪亚斯和塞拉听见有人敲她的房门。

<span style="color:#54a1f9">“是谁？”</span>塞拉问。

<span style="color:#df74b1">“是我，妈妈！”</span>

<span style="color:#54a1f9">“兹文！”</span>

她跑到门口把门打开。兹文冲进来，抱着手持终端兴奋地跳上沙发。

<span style="color:#54a1f9">“怎么了，兹文？”</span>

<span style="color:#df74b1">“我有好消息。是莉莉的事！”</span>

<span style="color:#54a1f9">“什么事？”</span>

<span style="color:#df74b1">“她说，她现在有点想回来了！”</span>

<span style="color:#54a1f9">“怎么回事？”</span>

<span style="color:#df74b1">“她说在北极的公民课上，老师讲到翔球，说它的计分规则很蠢，是维里迪亚人爱把简单事情搞复杂的典型例子。”</span>

<span style="color:#df74b1">“她一直用颈带跟我通话。我还把费布里克接了进来。我们把翔球的历史捋了一遍。她站起来跟老师讲：可以证明，如果计分方式是给每种球各定一个分值再相加，那几乎总是只专注一种球最好。但如果是相乘，那么你用某一种球得分时拿到的分数，会随着你靠另一种球已经得到的分数一起涨。所以均衡才划算。”</span>

<span style="color:#df74b1">“可老师不想听。他把手一摊，说这在现实生活里根本无所谓：现实生活里，你只专注一件事就能赢，北极人懂这一点，维里迪亚不懂，所以北极人赢。”</span>

<span style="color:#df74b1">“莉莉回他：可你想想个人生活和工作。如果你几乎每天从早到晚拼命干活，你能挣更多钱，能买更大的房子，可这房子，你只有不干活的那点时间才享受得到。这笔账一模一样！所以现实生活也需要均衡！”</span>

<span style="color:#df74b1">“然后她就被罚留堂了。”</span>

<span style="color:#df74b1">“所以她现在觉得北极人又差劲又蠢。他们嘴上说着追求最好，其实只在乎自己的权威。”</span>

<span style="color:#be9b00">“北极人中有些人是聪明的，”</span>格拉迪亚斯插话。<span style="color:#be9b00">“他们确实能造出很好的技术。可那个老师听上去就是个十足的废物。”</span>

<span style="color:#be9b00">“一个废物要是碰巧生在赢的队里，表现就正是这样。他们把全部自我认同都寄托在队上，全盘接受那些说法：自己的队为什么了不起，自己是哪个队的人就等于自己有多大的价值。然后他们根本不会察觉，那份了不起其实一点也不在他们自己身上，里面只是个可怜的空壳。”</span>

<span style="color:#54a1f9">“格拉德，别教兹文这样看人！”</span>

<span style="color:#be9b00">“兹文，对伤害别人的人刻薄一点，没关系。”</span>格拉迪亚斯继续说，语气越来越自以为是。<span style="color:#be9b00">“如果有人正遇上难处，或者只是不懂，那就帮他，对他好些。可要是有人拿自己根本不配的权威去敲别人的头，那就直接打回去。”</span>

<span style="color:#54a1f9">“格拉德！”</span>

<span style="color:#be9b00">“想打败北极人，我们就得学会有时至少让自己也带一点北极味。但一定把这股劲用在正道上。”</span>

塞拉叹了口气。

<span style="color:#54a1f9">“这么说，我倒是能理解。毕竟我们找到莉莉，用的正是北极人那套——监视一切。这算不算也带了一点北极味？”</span>

<span style="color:#be9b00">“大概算吧。”</span>

<span style="color:#be9b00">“不过我相信，要把亲人接回家，我们并不需要对自己全国的青少年搞无限制的摄像头监视。无限制的摄像头帮我们找到了莉莉，可也帮北极人差点把我们打垮。我相信泽已经知道某种更好的办法，既能拿到好处，又不用付那些代价。”</span>

<span style="color:#54a1f9">“等等……”</span>

<span style="color:#be9b00">“怎么了？”</span>

<span style="color:#54a1f9">“我觉得泽也许正是莉莉最合适的导师。她需要一个好榜样，让她知道真正的赢家是什么样——不是骑在别人头上、把别人按下去，而是愿意把别人托起来，希望别人也跟他一起赢。”</span>

<span style="color:#df74b1">“妈，爸？”</span>兹文插嘴。<span style="color:#df74b1">“那我们现在能为莉莉做点什么？”</span>

<span style="color:#54a1f9">“莉莉能自己离开北岸吗？”</span>

<span style="color:#df74b1">“我问过了。她说北岸的边境是开放的，可她在寄宿学校里，学校不放她走。”</span>

格拉迪亚斯哀叹一声。

<span style="color:#be9b00">“我想，别的先不说，等我们把北岸夺回来，3个孩子就都能回来了。”</span>

<span style="color:#54a1f9">“格拉德，莉莉那边该怎么建议，让我和白来想。她现在知道北极人有多差劲了，她想回家。但在把她接回来之前，她需要的是不会把她害死的建议。”</span>

格拉迪亚斯哼了一声，算是认了。

<p class="scene-break">3724年霜期18日</p>

<span style="color:#be9b00">“嗯，我刚收到莱克托的回音。”</span>格拉迪亚斯对塞拉说，她正在酒店房间里给自己倒茶。

<span style="color:#54a1f9">“他怎么说？”</span>

<span style="color:#be9b00">“他们昨天开了一次特别闭门会议。韦尔多也在。”</span>

<span style="color:#be9b00">“莱克托摆出了另一位将军受贿的证据。他把改革军方领导层的话题挑了起来。他采纳了白给的一条建议：把讨论引向一个方向，让反对者自己先去替现任最高将领说话，然后又说如果非得换人，另一位将军才是显而易见的人选。接着他亮出底牌，拿出更多证据——那位最高将领一直在跟一个人定期见面，后来查明那人是北极间谍；而他们提出的那位替代人选，也正被人要挟。”</span>

<span style="color:#be9b00">“之后，他提出了一套对付北极人的新思路：拿他们对 AI 的依赖做文章。他展示了一些针对北极无人机的漏洞利用，包括一段来自红郡的昆高培录像——不过他搪塞过去，说那是他在红郡认识的线人送给他的。”</span>

<span style="color:#be9b00">“成了，比他或白预想的容易得多。结果发现，对那些只是懒、只是累的议员来说，让莱克托照自己的意思去做才是阻力最小的路——因为那意味着官司立刻就能结束。而那些正被要挟的议员，只需要一个‘抵抗不现实’的借口；莱克托的论证，加上他们知道这桩官司早晚可能查到自己的处境，正好给了他们这个借口。于是莱克托现在是最高将领了。”</span>

<span style="color:#54a1f9">“这听起来是个完美的收尾。昆高培可以介入军方，可以和莱克托合作，而他和体系里其余大部分人还都在原位。所以我们不是进去把一切换掉，我们保住了连续性。这正是预测机器人想要的。”</span>

<span style="color:#be9b00">“一点没错。”</span>

<span style="color:#54a1f9">“那就这样，我们赢了？”</span>

<span style="color:#be9b00">“梅尔丹议事厅之战已经结束。北岸之战即将开始。”</span>
