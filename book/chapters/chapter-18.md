# 第十八章

<p class="dateline">帕佛盖都，泽国 · 3724年果月18日</p>

格拉迪亚斯走出空港，穿过一道密封的出口，门一开，直通一辆黑色大轿车的车厢。

泽和白都已经坐在车里：泽坐的是背朝车头的座位，白坐在他对面，面朝前方。

<span style="color:#be9b00">“你们一定就是泽和白吧。”</span>

<span style="color:#ed756b">“正是我们！”</span>白答道。

<span style="color:#be9b00">“总算见到你们了，我很高兴。”</span>

<span style="color:#df74b1">“我们也是。”</span>

格拉迪亚斯在泽左边坐下。

车门关上，车开始加速。

格拉迪亚斯朝右看，越过泽，望向车的右窗。

车驶出空港，很快经过一连串店铺。

格拉迪亚斯立刻觉出不对：车一动，窗上的景象就跟着移，可他挪动身子时，画面却毫无反应。

<span style="color:#be9b00">“那是真窗户吗？”</span>格拉迪亚斯问。

<span style="color:#df74b1">“也可以是。”</span>泽回答。<span style="color:#df74b1">“但现在安保规程升级了，黑色轿车的设置也改了。车窗不能直接透光，因为就算调暗，玻璃也是双向透的——外面拿一台好相机就能看出我们坐在里面。所以现在用的是仿真窗，靠摄像头把外面的景象拍进来。”</span>

<span style="color:#df74b1">“车里只有一个人的时候，效果其实很好，它还会追踪视线，画面调得更自然。可现在我们是两个人，它挑中了我。”</span>

<span style="color:#be9b00">“嗯。”</span>

格拉迪亚斯改从左窗往外看。他几次调整姿势试了试。颜色和景深都有些不太自然，除此之外却正常得让人意外。他继续看，仔细留意窗外的一切。

许多店铺的侧面都画着卡通动物，气泡框里用泽国语写着各种话，格拉迪亚斯一句也看不懂。

每间铺子里摆的货，格拉迪亚斯都能匆匆瞥见：手持终端、算力盒、灯、无人机、传感器。

一家卖算力盒的店，招牌上写着“MIN KUI”。

一家卖灯的店，招牌上写着“GUI SAU”，那些灯大多做成细长圆柱形。

但让他意外的是，开着门的店似乎只有寥寥几家。

楼都只有一两层，通向地下的楼梯却很多。

街上有人，但比他往常在维里迪亚见到的人要少——尽管帕佛盖都的密度明显高过他的家乡。

<span style="color:#df74b1">“hun fe bin jin zo de jan li gi。”</span>泽念出了声。

<span style="color:#be9b00">“嗯？”</span>格拉迪亚斯应道。

<span style="color:#df74b1">“啊，抱歉。戴颈带的人真多，我随口说说。”</span>

格拉迪亚斯还注意到，路面上有大量一模一样的黑色轿车。

<span style="color:#be9b00">“帕佛盖都人人都坐这种黑色轿车吗？这是为了隐私？”</span>他问。

<span style="color:#df74b1">“仔细想想，倒也不是。这车我们早就有了，但这么多人开始用，还是很新的事。几天前，路上还不到现在的一半。”</span>

三人继续默不作声地坐车前行。

几分钟后，车驶进一条隧道。走到中途，它减速停下。格拉迪亚斯感到轻轻一震，听到些机械的声响，车身似乎朝各个方向移动：先向上，再横移，然后向下。他透过车窗往外看，什么也看不见。大约半分钟后，这一套动作结束，车又像是重新加速向前。

<span style="color:#be9b00">“我们刚刚……换车了？”</span>

<span style="color:#df74b1">“换的是车厢。系统等10辆车到齐，把车厢随机互换，然后各自再开出去。守在出口的人，谁也不知道我们在哪一辆里。像混网，只不过换的是人。”</span>

不到一分钟，车出了隧道。很快，帕佛盖都南边的山体金字塔进入视野。

<span style="color:#be9b00">“那……真是座了不起的建筑，”</span>格拉迪亚斯说。

<span style="color:#df74b1">“嘿，人人都这么说。其实这座金字塔是我们从一座现成的山里凿出来的。”</span>

<span style="color:#be9b00">“还是很了不起！这样大概也更安全，要是内部有90%、甚至99%都是实心岩石的话。”</span>

<span style="color:#df74b1">“96.7。”</span>

<span style="color:#be9b00">“那空着的只有三十分之一？普通建筑要是10%实心，那这座的容量就等于一个每边都只有三分之一的普通建筑？”</span>

<span style="color:#df74b1">“答对了！”</span>

<span style="color:#df74b1">“也许你说得对，是该惊叹一下。它确实是全泽国这类建筑里最大的一座。”</span>

车开始减速，很快就停下。车门打开，门外直接就是酒店。

<span style="color:#df74b1">“这就是你住的酒店，格拉迪亚斯！”</span>

格拉迪亚斯站起身，提着包下了车。

<span style="color:#be9b00">“那接下来怎么安排？”</span>

<span style="color:#df74b1">“先休息一个长时，我们再回这儿找你，接着聊。”</span>

格拉迪亚斯走进酒店，把手表往最近的一个绿色圆圈上一贴。

手表震了一下。他拿到了房间钥匙。

格拉迪亚斯环顾四周。他发现泽说得没错，这里几乎所有人都已经戴上了颈带。

格拉迪亚斯走进电梯。电梯门合上。门再开时，他走出去，进了自己的房间。

---

格拉迪亚斯从酒店大门出来，朝外看。他只休息了40分钟，再过60分钟，泽和白就该等他了。他打算出去走走，至少亲眼看看帕佛盖都的这一片。

他转过身，看见了酒店的地址：檀凯街1565号。

他向右拐，开始往前走。

几乎立刻，手表就朝他闪出一连串警告，“未知”的数量到了两位数。他想着这不过是自己的维里迪亚手表认不得泽国的电子设备，决定不理这些警告，继续往前走。

他过了马路。一辆黑色轿车从他身边驶过，随即减速停下。一个男人从旁边的店里走出来，抱着一个大箱子，把箱子放在车旁的地上。

车门打开，司机走下车，也把一个大箱子放在地上，大小一模一样。她接着打开箱子的顶盖。

隔着几米看过去，格拉迪亚斯能看到箱子最上面一排摆着约30个更小的白盒子。

司机取出一只装着最上面一排货的托盘，放到台阶上。店里的男人掏出手持终端，似乎在同时扫描所有白盒子上的二维码。

司机又取出第二排的托盘，叠在第一只托盘上。店里的男人再扫一遍。

这样又重复了5次。接着，司机打开男人的大箱子，也一排一排地扫过去。

每扫完一排，她就把托盘放进自己的箱子。最后，她把箱子搬回车里，开走了。

<span style="color:#be9b00">“这是在干什么？”</span>格拉迪亚斯问。

<span style="color:#00bc96">“送货。”</span>那人答道。<span style="color:#00bc96">“高安全级的。”</span>

那人把台阶上的托盘都装进自己的箱子，抱起箱子匆匆回到店里，锁上了门。

格拉迪亚斯明白了，这就是实物投递混网——泽跟他讲过一次。每件物品都要经过几个承运人之手，没有哪一个人同时知道起点和终点。想破坏某一个人的设备，就必然要破坏所有人的设备——而真这么干，很快就会落网。

格拉迪亚斯继续走。他在十七街向右拐，正前方就能看见帕佛盖都那座巨大的山体金字塔，而通往它的坡道，再过两条街就开始了。

这条街上，开门的店铺多了许多。几乎每家店窗子上方都挂着招牌，一半做得精致专业，另一半是用霓虹灯临时手工拼出来的。他看见一家花店，顾客还不少。再往前大约20米，是一家服装店。外面的海报还在推销夹克，但透过窗子往里看，店里大约一半的空间已经被匆匆添置的隐私袍占去。再往前约20米，是一道没有招牌的楼梯通往地下室，两个十几岁的男孩和一个女孩正往下走。

楼梯口上方，格拉迪亚斯看到一块招牌。上面画着可爱的卡通动物在摆弄电子器件和化学实验器材，背景是绿树和蓝天。招牌正中，是一句泽国语的箴言：

他琢磨这些字是什么意思。

他在心里记下一笔：既然来了，那256个泽国语词根，得真的开始学了。

再往前约20米，他又看到一道楼梯，通向一家像是开在地下的茶馆。入口和楼梯的装饰风格，让格拉迪亚斯想起小时候看过的泽国中世纪的图画。

又过不久，格拉迪亚斯走到下一条街：津戈街。此前人行道上树荫很密，密到他一度看不见前方高耸的巨大金字塔。到了这个路口，树暂时断开，他又能看见它了。他看见许多人沿着通往入口的斜坡道上来下去，多数人穿着隐私袍。他不知道他们在做什么。

他过了马路，继续往前走，到了下一条街：宰贡街。这是山丘开始前的最后一条街。他又过了马路，开始沿坡往上走。

大约5分钟后，格拉迪亚斯已经站得够高，俯瞰着帕佛盖都，几乎能看见所有建筑的屋顶。从高处看，这座城市是混凝土屋顶和绿树的混合——比自由城绿得多，却仍远不如维里迪亚绿。

他注意到旁边有块大石头，便坐上去，看起了风景。

几分钟后，他开始往回下山。

他回到宰贡街，向左拐，沿着城市边缘一直走到最西端。一条绿树覆盖的漂亮小路似乎环绕着整座城市，他很是喜欢。他看见许多人在小路上散步、跑步。走到城西边缘的零街时，小路转向北。

他继续沿小路往北走了两条街，回到檀凯街，然后重新穿回城里，一路向东，回到了酒店。

---

格拉迪亚斯走进酒店，立刻向左拐进大堂餐厅。虽然他早到了10分钟，泽和白已经坐在一张桌边，正看着一台手持终端。白抬起头，朝他挥手。

格拉迪亚斯走到他们桌边坐下。

<span style="color:#be9b00">“在看什么？”</span>他问。

白把屏幕转给他看。

<span style="color:#ed756b">“你知道这是什么意思吗？”</span>

<span style="color:#be9b00">“第一行是维里迪亚人写的。”</span>

<span style="color:#ed756b">“没错。那后面的呢？”</span>

<span style="color:#be9b00">“还不知道。我只认得5个泽国语词根，”</span>格拉迪亚斯笑了。

<span style="color:#ed756b">“已经是这门语言的2%了。”</span>白答道。

<span style="color:#ed756b">“人应当做梦。一个人做梦，便不怕痛苦。10万人做10万个梦，痛苦就会怕他们。”</span>

<span style="color:#ed756b">“这是一首古诗。”</span>

<span style="color:#be9b00">“这意思跟我们那句差得不太远。”</span>

<span style="color:#ed756b">“没错。只不过你们是在开辟道路，而我们在这儿，是为了活命在拼。”</span>

她话音刚落，泽和白就一起转头，朝另一个正跑向桌边的人挥手。

泽立刻认出了他，把剩下的那把椅子拉出来，让他坐下。

<span style="color:#df74b1">“格拉迪亚斯，这位是芬。”</span>

<span style="color:#be9b00">“幸会，芬。塞拉跟我提过，泽说了你不少好话。”</span>

<span style="color:#ce9200">“我也很高兴认识你，格拉迪亚斯。泽带来的人，就是我的朋友。”</span>

<span style="color:#be9b00">“我倒只是高兴，终于能亲眼看看泽国了。”</span>

<span style="color:#ed756b">“芬，你那边最近怎么样？”</span>白插话道。<span style="color:#ed756b">“我们差不多有半个月没见着你了。”</span>

<span style="color:#ce9200">“这么久没理你们，我真的很抱歉。不过谢谢你问这个问题——因为我总算能给出一个配得上它的答案了。”</span>

格拉迪亚斯、泽和白都转头盯着芬。

<span style="color:#ce9200">“你们可能一直奇怪，”</span>芬开口，<span style="color:#ce9200">“我们为什么要在班孙培上花这么多力气。优化泽国语、优化度量单位，搞这一切到底有什么意义——泽国明明还有那么多急需的事：教育、国防、经济发展，样样都缺。”</span>

<span style="color:#ce9200">“我自己也疑惑了好些年。直到红郡遭袭那天，我在班孙培的会上，才终于找到了答案。”</span>

<span style="color:#df74b1">“答案是什么？”</span>泽问。

<span style="color:#ce9200">“泽国语就是协调训练。”</span>

泽和白都张大了嘴。

<span style="color:#ce9200">“想想看，我们每发布一版新的泽国语，到底是在做什么。”</span>

<span style="color:#ce9200">“首先，我们拿许多不同的版本做 A/B 测试。我们鼓励不同的人去试不同的方案，再把各自的体验反馈回来。”</span>

<span style="color:#ce9200">“这保证了两件事。第一，保证整个过程里有公众反馈，所以最终成品参考的，是真人开始照着做时，哪些做法真的行得通。”</span>

<span style="color:#ce9200">“第二，公众反馈，加上最终结果是许多人在许多维度、许多选项之间选出来的——这两点能让人更容易接受结果。没有人会觉得意外。对其中某一部分有异议的人，几乎总认识某个更喜欢它的人，至少也能听听对方的看法。”</span>

<span style="color:#ce9200">“班孙培有意从各行各业招人——你要是招来一个组织里谁都不认识的人，还能拿到奖励。”</span>

<span style="color:#ce9200">“所以红郡遭袭那天，班孙培在线召开会议，做了一个前所未有的决定：至少暂时把泽国语第九版搁置。只放出几项谈了一年多的基础高亮改动，仅此而已。”</span>

泽松了一口气，叹息声清晰可闻。

格拉迪亚斯能理解。过去一个月，谁的日子都不好过——这时候让全国人都去学一门语言的新版本，实在不是好时机。

<span style="color:#ce9200">“他们转而决定用完全相同的一套机制，只是情况特殊、时间又紧，所以公众参与更少、保密更多，用这套机制来协调泽国全国另一整套完全不同的变化。”</span>

<span style="color:#ce9200">“你们看见了吗，现在多了多少人戴颈带、用颈带讲话？多了多少人穿隐私袍？多了多少人坐黑色轿车来往？多了多少人在网上下单、走实物投递混网，不再去实体店。而比这些重要10倍的，是你们看不见的：更多敏感会议干脆搬到了线上，所有在互联网上做事的人，用的工具也安全得多。蓝鲸通讯几乎在一夜之间从泽国消失了。”</span>

<span style="color:#ce9200">“3天前，这些都还没有发生。班孙培转而做的，只是把它那套新的隐私与安全建议，从那个渠道发了出去——关注它的人本来都在那儿等着泽国语第九版的消息。全国大约5%的人同时看到了这份建议。他们很意外，但读懂了理由，也尊重做决定的人。这些人里大多数已经在至少一件要紧的事上改变了行为，而哪怕只有2.5%，也足以掀起一股如今正席卷整个泽国的潮流。”</span>

芬越说越兴奋，接着往下讲。

<span style="color:#ce9200">“北极人总在讲一个人的智力分，讲社会该由分数最高的人来治理。维里迪亚有几位学者说，情商分也该被认真对待——可除了让人点头称是，他们从来没能让大家真的做点什么。”</span>

<span style="color:#ce9200">“但他们完全漏掉了第三类：协调分。协调分不是一个人的属性，而是整个共同体的属性。它是一个共同体做集体决策的能力：在零和竞争与正和合作之间选择后者——哪怕合作对个人有风险；也是从一个不良均衡跳进更好均衡的能力。”</span>

<span style="color:#ce9200">“北极人以为，这种事只能靠一个人人叩拜的强势领袖来做。但我们泽国人说不。我们说‘gie fe kiu kai ci bin hu’——扎根，无首。如今我们的根已经扎下；我们泽国人8次改进、完善自己的语言，没有自上而下的强制，也没有首领。现在，我们就要凭这样一个无首之身去迎战北极人。而我们一定会赢。”</span>
