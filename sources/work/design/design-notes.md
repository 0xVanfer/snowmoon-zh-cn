# 《雪月》阅读站设计决策

## 1. 信息架构
- `index.html`：站标 → 书名/副题 → 作品与非官方译本简介 → 开始/继续阅读/目录 → 阅读设置简介 → GitHub、Issues、联系邮箱 → GPL-3.0-only、免责声明、构建日期。
- `toc.html`：返回主页 → 目录标题/进度 → 32章列表（中文章名、Chapter N、地点日期、已读/当前）→ 页脚。
- `read/chapter-NN.html`：跳转正文链接 → 顶栏（主页/目录/设置）→ 章节标题/日期 → 双语标签 → 正文 → 章末上章/目录/下章 → 底栏（翻屏、章进度）。
- 目录抽屉：标题/关闭 → 当前章 → 完整目录。
- 设置面板：关闭 → 字号/行距/字体 → 主题 → 滚动/分页 → 语言 → 同步开关。
- 抽屉与设置互斥；所有章节使用真实链接。继续阅读定位至保存章；没有记录时隐藏。

## 4. 双语算法
测量正文可用宽W、高H、字号F，沟槽G=32px：
进入分栏：`W≥68F+G+32 且 W/H≥1.15`；
退出：`W<68F+G 或 W/H<1.05`；滞回防抖。
ResizeObserver监听容器，缺失则监听resize。
宽屏英文左、中文右，独立滚动；窄屏固定标签默认中文。
同步默认关；开启后主动栏百分比
`p=scrollTop/max(1,scrollHeight-clientHeight)`，
另一栏定位至p乘其可滚动高度；rAF合并事件并锁住程序触发，避免回环。
每种语言分别保存百分比、页码；重排先保存再恢复，不强制段落对齐。

## 5. 分页
DOM骨架：main → reader → pane[data-lang] → viewport → flow；
章末导航位于flow末尾。两份正文各仅注入一次。
flow用固定高度H、列宽W、间隔32px的CSS多列；viewport裁切，平移整列。
步长S=W+32；页数`ceil((scrollWidth+32)/S)`，页码从0起。
图片等比限制在W×H；超高终端/表格放入最大高H的内部滚动容器，横向溢出同理；普通段落允许跨列。
图片加载、字号或尺寸变化后重算并按原百分比恢复。
末页再次前进到下一章；首页后退到上章末页，首末章使用契约链接返回目录。
对照分页各栏独立；同步时按页码百分比映射，活动栏决定跨章。

## 6. 状态与存储
状态：菜单显示/隐藏、浮层无/目录/设置、活动语言、翻页模式。
正文左/中/右各1/3：前进反向/显隐菜单/前进；滚动一步为可见高85%。
链接、控件、内部滚动区、选区及拖动不触发；不阻止触摸原生滑动。
←/→翻屏，到边界翻章；↑/↓滚动活动栏；Esc先关浮层再切菜单；t循环主题，d循环中文/英文/对照。输入控件内不接管快捷键。
键` snowmoon.reader.v1 `（去首尾空格）：
`{"v":1,"last":1,"settings":{"size":20,"leading":1.8,"font":"serif","theme":"paper","mode":"scroll","lang":"zh","sync":false},"chapters":{"1":{"zh":{"y":0,"p":0,"page":0},"en":{"y":0,"p":0,"page":0},"tab":"zh","read":false}}}`
滚动节流300ms保存，pagehide补存；到末尾标已读。解析、写入均捕获异常并校验范围；失败只用内存。

## 7. 无障碍与打印
无JS默认中文完整流式显示、英文隐藏。h1页面标题/h2正文章名；图片必有alt。
焦点3px强调色轮廓；触点至少44px。浮层有dialog、名称、焦点圈定、关闭后归还焦点；按钮维护aria-expanded，标签遵循tab语义。
中文用strict断行及text-spacing-trim；减少动态偏好禁动画。
打印解除高度、列、平移、裁切与终端滚动限制；隐藏控件、去底纹。只打印当前语言，分栏时打印两语且英文在前。

## 8. 不做
不依赖网络、fetch、字体下载或包；不改占位符；不复制正文；不逐段硬对齐；不让终端span破坏flex刻度；不加广告、登录、弹窗、自动播放、无限滚动或强制全屏；不把触摸滑动劫持为翻页。
